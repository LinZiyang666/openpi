## 0. 这份文档要回答的问题

一个 **training-free 的检索式 cache**：把 teacher policy 的 rollout 记成 `(key, action)` 条目，运行时用当前观测的 key 检索最近邻，直接复用其动作。

问题：**把历史帧纳入检索相似度，能否提升检索质量？**

本文证明：在本系统的两条结构假设（teacher 无记忆；key 只依赖当前观测）下，这个问题**没有无条件的是/否答案**，但可以被完整分解为三个可分别回答的子问题：

1. **信息的来源与上界**（§2–§4）：历史能携带的关于检索目标的信息被 key 的有损度从上方封死（引理 2）；该上界在允许的模型类中可以取到，也可以为零（命题 2.2），其数值由环境、teacher 映射与 key 共同决定，两条结构假设只决定上界的**形式**。历史信息中可由"阶段变量"解释的部分可以被精确剥离（命题 3）。
2. **信息到误差的兑现**（§5）：信息为正只在对数损失的 Bayes 最优意义下恒等于误差改善（定理 4）；对一般损失只有单向保证，而在固定的有限库检索算子上，加历史的效果符号可正可负（命题 4.2）。
3. **算子的表达力**（§7）：生产使用的"逐帧标量化 + 非负可加"打分类，取不到标量化之前的帧间关系特征，也实现不了任何需要负响应的趋势判别（命题 6）。

此外存在一个结构性的**例外通道**：对库做基于结局的筛选（例如只保留成功轨迹）是 collider 条件化，可以把历史信息重新注入标签分布（命题 5）。

§8 把各命题与本项目实验逐条对应；§9 列出全部假设与本文**不**主张的内容。

## 1. 设定与记号

| 符号 | 含义 |
|---|---|
| $o_t \in \mathcal{O}$ | $t$ 时刻的观测（图像 + 本体状态 + 语言指令） |
| $h_t \in \mathcal{H}$ | 历史，$h_t := (o_{<t}, a_{<t})$ |
| $\pi$ | teacher policy，**无记忆**：$a_t \sim \pi(\cdot \mid o_t)$ |
| $\xi_t$ | teacher 的内部采样噪声（flow-matching 的随机源） |
| $k: \mathcal{O} \to \mathcal{K}$ | key builder，**确定性且通常有损**；记 $k_t := k(o_t)$ |
| $a^*_t$ | **检索目标**：库中与观测 $o_t$ 配对存储的标签，即 $a^*_t = \pi(o_t; \xi_t)$ |
| $\mathcal{L} = \{(k(o^{(i)}), a^{*(i)})\}_i$ | 离线库 |

所有随机变量定义在同一概率空间上；$I(\cdot;\cdot\mid\cdot)$ 为条件互信息，$H$ 为熵。约定 $I \ge 0$，链式法则 $I(X; Y,Z \mid W) = I(X;Y\mid W) + I(X;Z\mid Y,W)$。

**假设 A0（正则性）**：文中出现的全部信息量均良定且有限；连续变量情形假设相对某 σ-有限支配测度的条件密度存在，条件分布取正则版本。

**假设 A1（teacher 无记忆）**
$$a^*_t = f(o_t, \xi_t), \qquad \xi_t \perp\!\!\!\perp (h_t, o_t).$$

> 这不是建模选择，而是对 $\pi_{0.5}$ 架构的陈述：它的前向只吃当前帧、本体状态与指令，不含任何跨时刻状态。采样噪声每次独立抽取，故 $\xi_t \perp h_t$。

**假设 A2（key 是观测的函数）**：$k_t = k(o_t)$，$k$ 确定性。

> 由构造成立：key builder 只吃当前帧。

## 2. 引理 1（标签条件独立）

**引理 1.** 在 A1 下，
$$\boxed{\,I(a^*_t \,;\, h_t \mid o_t) = 0\,}$$

**证明.** 由 A1，给定 $o_t = o$，
$$P(a^*_t \in \cdot \mid o_t = o,\, h_t = h) = P\big(f(o, \xi_t) \in \cdot \mid o_t=o,\ h_t=h\big) = P\big(f(o,\xi_t)\in\cdot\big),$$
最后一步用了 $\xi_t \perp (o_t, h_t)$。右端不依赖 $h$，故条件分布与 $h_t$ 无关，即 $a^*_t \perp h_t \mid o_t$，其条件互信息为零。$\blacksquare$

**读法.** 这是**继承定律的本体**：teacher 无记忆 ⇒ 它生成的标签在给定当前观测后与历史独立。证明本身平凡，重要的是它**限定了条件变量是完整观测 $o_t$**；下一节说明为什么这个限定不能省略。

**本项目是否检验过？** ✗ 未检验，也**无法**检验：估计 $I(a^*;h\mid o_t)$ 需要以完整观测为条件，而完整观测（原始图像）并未随库存储。本项目的所有实验都以 $k_t$ 为条件。现有结果中没有任何一条与引理 1 冲突。

## 3. 引理 2（去噪上界）：上界、紧性与非单调性

**引理 2.** 在 A1、A2 下，
$$\boxed{\,I(a^*_t \,;\, h_t \mid k_t) \;\le\; I(a^*_t \,;\, o_t \mid k_t)\,}$$

**证明.** 考虑联合量 $I(a^*_t; h_t, o_t \mid k_t)$，用链式法则两种展开。

*展开一（先 $o$ 后 $h$）*：
$$I(a^*_t; h_t, o_t \mid k_t) = I(a^*_t; o_t \mid k_t) + I(a^*_t; h_t \mid o_t, k_t).$$
由 A2，$k_t = k(o_t)$ 是 $o_t$ 的确定性函数，故以 $(o_t, k_t)$ 为条件等同于以 $o_t$ 为条件，于是第二项 $= I(a^*_t; h_t \mid o_t) = 0$（引理 1）。因此
$$I(a^*_t; h_t, o_t \mid k_t) = I(a^*_t; o_t \mid k_t). \tag{3.1}$$

*展开二（先 $h$ 后 $o$）*：
$$I(a^*_t; h_t, o_t \mid k_t) = I(a^*_t; h_t \mid k_t) + \underbrace{I(a^*_t; o_t \mid h_t, k_t)}_{\ge 0} \;\ge\; I(a^*_t; h_t \mid k_t). \tag{3.2}$$

合并 (3.1)(3.2) 即得。$\blacksquare$

**读法.** 右端 $I(a^*; o \mid k)$ 是**"给定 key 之后，完整观测还能补充多少关于标签的信息"**，即 **key 的有损度**：

> **历史在检索中能贡献的信息量，被 key 丢失的信息量从上方封死。**
> 历史的角色是"补 key 之失"，不是"引入新通道"。任何 $I(a^*;h\mid k) > 0$ 的观测都不是对本引理的反例，而恰在其允许的范围内。

**推论 2.1（key 充分 ⇒ 历史无用）.** 若 $I(a^*; o \mid k) = 0$，则 $I(a^*; h \mid k) = 0$，历史严格无增量。

**命题 2.2（上界的紧性与双向非蕴含）.** 在 A1、A2 下：

1. 存在模型使 $I(a^*;h\mid k)=0$；
2. 存在模型使 $I(a^*;h\mid k)=I(a^*;o\mid k)=1$ bit；
3. 因而 A1、A2 既不能推出"历史无增量"，也不能推出"历史有正增量"；引理 2 的上界在允许的模型类中是紧的。

**证明.** 两个构造共用同一 teacher（确定性无记忆 $a^* = o$）与同一 key（常数 $k \equiv 0$），只改环境的时序联合分布。

- *零增量模型*：各时刻状态独立同分布，$o_t = B_t$，$B_t \sim \mathrm{Bernoulli}(1/2)$ i.i.d.。历史只含与 $B_t$ 独立的 $B_{<t}$，故 $I(a^*;h\mid k) = I(B_t; B_{<t}) = 0$。
- *满增量模型*：整个 episode 保持同一隐藏比特 $B$，$o_t = B$，历史含 $o_{<t} = B$。则 $a^* = B$ 且 $h$ 决定 $B$，$k$ 为常数，故
  $$I(a^*;h\mid k) = H(B) = 1 \text{ bit} = H(a^*) = I(a^*;o\mid k),$$
  上界取等。$\blacksquare$

**读法.** "teacher 的输入决定上界"须准确理解为：**A1、A2 决定上界的形式**；上界的数值 $I(a^*;o\mid k)$ 由观测分布、teacher 映射与 key builder 共同决定，实际的历史增量还取决于环境如何把 $h$ 与 $o$ 关联起来。

**引理 2.3（上界随 key 退化单调变松）.** 若 $k_w = g(k_s)$ 是 $k_s$ 的确定性粗化（两者均为 $o$ 的函数），则
$$I(a^*; o \mid k_w) \;\ge\; I(a^*; o \mid k_s).$$

**证明.** 由 $k = k(o)$ 有 $I(a^*;o\mid k) = H(a^*\mid k) - H(a^*\mid o)$。第二项与 key 无关；第一项中 $\sigma(k_w) \subseteq \sigma(k_s)$，条件化于更粗的信息给出更大条件熵，$H(a^*\mid k_w) \ge H(a^*\mid k_s)$。$\blacksquare$

**备注 2.4（剂量-反应不是定理）.** 上界随 key 退化单调变松（引理 2.3），但**被界的量 $I(a^*;h\mid k)$ 本身不随 key 退化单调变化**。反例：$X, Y$ 为独立均匀二元变量，$o=(X,Y)$，$a^*=X$，$h=Y$。取 $k_s = X \land Y$ 与其粗化 $k_w \equiv 0$，记 $h_2$ 为二元熵，则
$$I(a^*;o\mid k_s) = \tfrac34 h_2(\tfrac13) \approx 0.6887,\qquad I(a^*;h\mid k_s) = \tfrac34 h_2(\tfrac13) - \tfrac12 \approx 0.1887,$$
$$I(a^*;o\mid k_w) = H(a^*) = 1,\qquad I(a^*;h\mid k_w) = I(X;Y) = 0.$$
key 的有损度从 $0.6887$ 增到 $1$ bit，历史的条件互信息却从 $0.1887$ 降到 $0$。因此"key 越弱历史越有用"（rescue-the-weak 的定理化）只能作为**待检验的经验假说**，不是引理 2 的推论。

**本项目是否检验过？** ✓ E1（LOEO、与生产同构的 kNN、欧氏动作残差）在 4 个 primary cell 中的 3 个给出 Holm 校正后区间下界 > 0 的残差改善：spatial B-d3 +5.35%、C-g1.0 +8.80%，libero_10 B-d3 +2.86%。按 §5 的方向规则，这构成"左端为正"的**算子特定定性证据**（若 $a^* \perp h \mid k$，历史特征在 kNN 度量中只是噪声维度，跨 suite、过校正的系统性改善与之难以相容）；它**不是**互信息的数值估计，残差百分比与 bit 之间没有量纲对应。结果落在引理 2 允许的范围内。剂量-反应（备注 2.4）在本项目**未被真正检验**：6 个 key builder 的质量代理跨度仅 2.6%~7.5%，自变量无动态范围（见 `exp/markov_sufficiency/analysis/e1_residual.md` §8）。

## 4. 命题 3（阶段分解）

引理 2 只给上界，不说明左端由**哪个维度**贡献。本节把"历史的增量其实只是阶段坐标"这一断言形式化。

设 $\phi_t$ 为**阶段变量**。分两种情形。

**命题 3（阶段分解）.**

**(i) 在线阶段的精确分解.** 若 $\phi_t = \varphi(h_t)$ 是历史的函数（例如 inference-cycle 序号 $c_t$，它等于历史的长度，在推理时在线可得），则**恒等式**
$$I(a^*; h \mid k) \;=\; I(a^*; \phi \mid k) \;+\; I(a^*; h \mid k, \phi)$$
成立。特别地，若还有
$$I(a^*_t \,;\, h_t \mid k_t,\ \phi_t) = 0, \tag{4.1}$$
则 $I(a^*;h\mid k) = I(a^*;\phi\mid k)$：历史的全部增量**恰好等于**阶段信息。

**(ii) 一般阶段变量的上界.** 若 $\phi_t$ 为任意随机变量且 (4.1) 成立，则
$$I(a^*; h \mid k) \;\le\; I(a^*; \phi \mid k),\qquad \text{且缺口恰为}\quad I(a^*;\phi\mid k) - I(a^*;h\mid k) = I(a^*;\phi\mid k, h) \;\ge\; 0.$$
等号成立当且仅当 $I(a^*;\phi\mid k,h)=0$（特别地，当 $\phi$ 是 $(k,h)$ 的函数时自动成立，即情形 (i)）。

**(iii) 风险版（任意损失）.** 在 (4.1) 与 A0 下，$(k,h)$ 是 $(k,\phi)$ 的 garbling，故对任意损失 $\ell$ 有 $R^\star_\ell(k,\phi) \le R^\star_\ell(k,h)$（$R^\star$ 见 §5）。

**证明.** (i) 由 $\phi = \varphi(h)$，$I(a^*; h, \phi \mid k) = I(a^*; h \mid k)$；另一方向展开 $= I(a^*;\phi\mid k) + I(a^*;h\mid k,\phi)$，两式相等即得恒等式。(4.1) 令末项为零。

(ii) 展开 $I(a^*; h,\phi \mid k)$ 两次：
$$I(a^*;\phi\mid k) + \underbrace{I(a^*; h \mid \phi, k)}_{=0 \text{ 由 }(4.1)} \;=\; I(a^*;h\mid k) + I(a^*;\phi\mid h,k),$$
移项即得缺口恒等式，非负性给出不等式。

(iii) 由 (4.1)，$P(a^*, h \mid k,\phi) = P(a^*\mid k,\phi)\,P(h\mid k,\phi)$，故可从 $(k,\phi)$ 用与 $a^*$ 无关的核 $P(h\mid k,\phi)$ 抽样出 $h'$，使 $(k,h')$ 与 $a^*$ 的联合分布同 $(k,h)$。任何基于 $(k,h)$ 的决策规则据此可由 $(k,\phi)$ 加私有随机化模拟，风险不变，取下确界即得。$\blacksquare$

**备注 4.1（(ii) 的缺口可以严格为正）.** 取 $k$ 为常数，$a^* = \phi \sim \mathrm{Bernoulli}(1/2)$，$h = \phi \oplus N$，$N \sim \mathrm{Bernoulli}(p)$ 独立，$0<p<1/2$。则 (4.1) 成立，而
$$I(a^*;h\mid k) = 1 - h_2(p) \;<\; 1 = I(a^*;\phi\mid k),$$
缺口 $= I(a^*;\phi\mid k,h) = h_2(p) > 0$。故仅由 (4.1) 不能推出"历史增量 ≈ 阶段信息"；要取等需情形 (i) 或 $I(a^*;\phi\mid k,h)\approx 0$。

**备注 4.2（阶段变量的在线性）.** 归一化进度 $\phi_t = c_t/(C-1)$ 含 episode 的**最终**总 cycle 数 $C$。若 $C$ 非预先固定，则该 $\phi_t$ 不是 $o_{\le t}$ 或 $h_t$ 的函数，而是使用未来信息的离线量，且可能与终止时刻或结局相关。它可用于**描述性对齐**，但不能在无附加假设时解释为"给 key 补上一个在线阶段坐标"。干净的在线选择是 $c_t$ 本身（推理时系统知道自己的 cycle 序号）或以库侧每任务常数归一化的 $c_t$；对这两者，情形 (i) 的精确分解直接适用。另注意：若实验中的"历史"是定长窗口的过去 key（不含 $t$ 本身），则 $c_t$ 不是该窗口的函数，须作为显式条件变量加入。

**本项目是否检验过？** ✓ E1-O 把候选池限制到 $|\phi(\text{query}) - \phi(\text{candidate})| \le \varepsilon$ 后重测历史增益：**8 个 cell（2 suite × 2 个 $\varepsilon$ × 2 个 depth）无一支持历史有残余增量**；libero_spatial 在 $\varepsilon=0.05$ 下相对增益为**精确的 0.00%**（未对齐时 B-d3 的 +5.35% 完全消失）。候选池未退化（对齐后中位 8–20 个候选，最小 3 个）。两点限定：其一，E1-O 用的 $\phi$ 是按总长归一化的离线进度（备注 4.2 的 oracle 情形），故它是描述性对齐；其二，零结果是**算子特定证据**，不能等同于条件独立 (4.1) 获证。在此限定下，实测与"历史携带的几乎全部是阶段信息"一致；在线版（以 $c_t$ 对齐）待做。

## 5. 定理 4（风险与信息）：单调性、对数损失恒等式与主不等式链

前三节讲信息，本节把它接到**可达的误差**上，并明确"信息为正"与"误差改善"之间的关系依赖于损失。

设检索系统输出 $\hat a_t = g(\cdot)$，$g$ 为任意可测函数。对变量集 $\mathcal{S}$ 与损失 $\ell$，记**贝叶斯风险**
$$R^\star_\ell(\mathcal{S}) := \inf_{g \text{ 可测}} \mathbb{E}\big[\ell\big(g(\mathcal{S}),\, a^*_t\big)\big].$$

**定理 4.**

**(i) 单调性（任意损失）.** $R^\star_\ell(k_t, h_t) \le R^\star_\ell(k_t)$。

**(ii) 零信息 ⇒ 无改善（任意损失）.** 若 $I(a^*;h\mid k)=0$，则 $R^\star_\ell(k,h) = R^\star_\ell(k)$ 对一切 $\ell$ 成立。

**(iii) 对数损失恒等式.** 设预测器输出条件分布 $q(\cdot\mid\mathcal{S})$，损失取对数评分 $\ell_{\log}(q, a) = -\log q(a)$（连续情形相对支配测度取密度，A0 保证诸量有限）。则
$$R^\star_{\log}(k_t) - R^\star_{\log}(k_t, h_t) = I(a^*_t; h_t \mid k_t).$$
特别地，在对数损失的 Bayes 最优意义下：**历史能降低误差 $\iff I(a^*_t; h_t \mid k_t) > 0$**。

**证明.** (i) 任何只用 $k$ 的 $g$ 都是同时用 $(k,h)$ 的特例。

(ii) $I(a^*;h\mid k)=0$ 即 $P(a^*,h\mid k)=P(a^*\mid k)P(h\mid k)$，故 $(k,h)$ 可由 $k$ 加与 $a^*$ 无关的私有随机化模拟（garbling 论证，同命题 3(iii)），于是 $R^\star_\ell(k,h) \ge R^\star_\ell(k)$；与 (i) 合并得等号。

(iii) 对数损失下贝叶斯风险即条件熵：$R^\star_{\log}(\mathcal{S}) = H(a^*\mid\mathcal{S})$，故差为 $H(a^*\mid k) - H(a^*\mid k,h) = I(a^*;h\mid k)$。$\blacksquare$

**备注 5.1（(iii) 的"⟸"方向不能推广到一般损失）.** 取 $k$ 常数，$h\sim\mathrm{Bernoulli}(1/2)$，$P(a^*=1\mid h=0)=0.8$，$P(a^*=1\mid h=1)=0.9$。则 $I(a^*;h)>0$（两个条件分布不同），但 0-1 损失下无论是否观察 $h$，Bayes 决策恒为 $1$，两侧风险同为 $\tfrac12(0.2+0.1)=0.15$；一维绝对误差同理。因此对欧氏 / 0-1 这类损失，只有单向读法可用：**Bayes 层面的改善 ⇒ $I>0$；$I>0$ 不保证改善；无改善不证明 $I=0$。** 这正是解读本项目实验（欧氏残差）时必须使用的方向规则。

**推论 4.1（继承定律的可操作形式，对数损失）**
$$\boxed{\;0 \;\le\; R^\star_{\log}(k_t) - R^\star_{\log}(k_t, h_t) \;=\; I(a^*_t; h_t\mid k_t) \;\le\; I(a^*_t; o_t \mid k_t)\;}$$
即：**在检索式 cache 中，引入历史所能带来的（对数损失、Bayes 最优意义下的）模仿误差改善，不超过 key 相对完整观测的信息损失。teacher 无记忆决定了这条上界的形式，与环境是否 POMDP 无关。**

**备注 5.2（关于"成功率天花板"的诚实说明）.** 从模仿误差推到 rollout 成功率需要额外假设（例如 obs-MDP 加误差到回报的单调性），且 teacher 本身并非最优策略：检索误差偶然改善回报在原则上不能排除。**本文不声称成功率意义上的天花板定理**；其严格化留待后续。

**命题 4.2（固定检索算子上符号不定）.** Bayes 单调性（定理 4(i)）**不迁移**到固定的有限库检索算子。存在满足 A1、A2 的模型与有限库，使得对生产式打分 $S(x) = s_0(x) + \lambda s_1(x)$（$\lambda > 0$，取最大分候选）：加入历史项使检索**变差**；亦存在使其**变好**的模型与库。

**证明（构造）.** 取 $\lambda = 0.2$，两个候选 $G$（动作正确）与 $B$（动作错误）。

*变差的构造*：$s_0(G)=1.0,\ s_1(G)=0.0$；$s_0(B)=0.9,\ s_1(B)=1.0$。只用当前帧选 $G$（$1.0>0.9$）；加历史后 $S(B)=1.1>1.0=S(G)$，改选 $B$。

*变好的构造*：$s_0(G)=0.9,\ s_1(G)=1.0$；$s_0(B)=1.0,\ s_1(B)=0.0$。只用当前帧选 $B$；加历史后改选 $G$。

这些相似度值可由单位向量的余弦实现，标签可由确定性无记忆 teacher 生成，与 A1、A2 不冲突。$\blacksquare$

**读法.** 对固定检索器而言，"加入历史后误差变化的符号"不是信息论定理；它同时取决于有限库的几何、权重、tie-breaking、候选覆盖与标签分布。**"E1 测得历史信息为正"与"rollout 上加历史 SR 下降"并存，正是本命题允许的组合**，二者没有矛盾。

**本项目是否检验过？** ✓（在方向规则的限定下）E1 的损失为欧氏残差，定理 4(iii) 的等号不适用，适用的是 (i)(ii) 与备注 5.1 的方向规则。E4 在 rollout 上复现了 spatial 的 depth 退化（$A2-A0 = -3.47$pp，CI 排除 0），与 E1 的正信息并存，落在命题 4.2 的允许范围内。

## 6. 命题 5（例外通道：选择条件化）

引理 1 的结论 $I(a^*;h\mid o)=0$ 有一个**结构性例外**：若库的形成过程按某个同时受历史与动作影响的变量做过筛选，则条件化在一个 collider 上，可以**重新注入**历史信息。成功筛选是其中最重要的实例。

设 $Z \in \{0,1\}$ 为 episode 成功指示。因果结构上 $Z$ 同时受 $h_t$（历史决定了真实分支）与 $a^*_t$（当前动作对不对）影响，故 $Z$ 是 $h_t \to Z \leftarrow a^*_t$ 的对撞点，条件化在 $Z=1$ 上会打开这条路径。

**命题 5.** 存在满足 A1 的模型，使得
$$I(a^*_t; h_t \mid o_t) = 0 \quad\text{但}\quad I(a^*_t; h_t \mid o_t,\ Z=1) = 1 \text{ bit}.$$

**证明（构造 + 闭式计算）.** 两分支观测混叠任务：

- 隐藏分支 $B \in \{\mathrm{L}, \mathrm{R}\}$，$P(B=\mathrm{L}) = 1/2$；
- 观测 $o$ 对两分支**完全相同**（混叠），故 $o \perp B$；
- 历史 $h$ **完全决定** $B$（例如开局时看到过路标）；
- 正确动作依赖分支：分支 $\mathrm{L}$ 下为 $a_\mathrm{L}$，分支 $\mathrm{R}$ 下为 $a_\mathrm{R}$，$a_\mathrm{L}\ne a_\mathrm{R}$；
- teacher 无记忆，只见 $o$，故均匀猜：$a^* \sim \mathrm{Unif}\{a_\mathrm{L}, a_\mathrm{R}\}$，且 $a^* \perp B$（满足 A1）；
- 成功当且仅当动作与分支匹配：$Z = \mathbf{1}\{(B,a^*) \in \{(\mathrm{L},a_\mathrm{L}), (\mathrm{R},a_\mathrm{R})\}\}$。

*未过滤*：$a^* \perp B$ 且 $h$ 只通过 $B$ 影响一切，故给定 $o$ 有 $a^* \perp h$，即 $I(a^*;h\mid o) = 0$，teacher 成功率 $P(Z=1) = 1/2$。

*条件在 $Z=1$*：此时 $(B, a^*)$ 只能取 $(\mathrm{L},a_\mathrm{L})$ 或 $(\mathrm{R},a_\mathrm{R})$，各以 $1/2$ 出现。给定 $Z=1$，$a^*$ 由 $B$ 唯一决定，而 $h$ 唯一决定 $B$：
$$H(a^*\mid o, Z=1) = 1 \text{ bit}, \qquad H(a^*\mid o, h, Z=1) = 0,$$
故 $I(a^*; h \mid o, Z=1) = 1$ bit。$\blacksquare$

**含义.** 在 success 过滤的库上，检索若能用历史匹配到"同分支"的条目，成功率可由 50% 提升到 100%。这是历史在本框架内**唯一的结构性正面通道**，也是"记忆假肢"实验要构造的正对照。

**备注 6.1（通道的一般形式）.** success 过滤是实例而非全部：只要选择变量 $S$ 的条件分布 $P(S\mid a^*, h, o)$ 同时依赖 $a^*$ 与 $h$，即使原分布满足 $a^* \perp h \mid o$，选择后的分布中也可能有 $I(a^*;h\mid o, S{=}1) > 0$。成功筛选、人工挑选、删失、按未来回报加权采样都属于这类机制。注入量的大小受环境混叠程度控制：若环境近似 obs-MDP（$P(Z\mid o, a, h) \approx P(Z\mid o, a)$），则通道近似关闭。

**本项目是否检验过？** ✗ 未检验。两点如实记录：其一，所用 artifact 的条目 `outcome = None` 且检索未启用 `QueryFilter.outcome`，但这只说明**字段缺失与检索未消费**；库构建管线的 `--outcome-filter` 默认取 `success`，上游的成功筛选大概率已经发生，故本通道在数据分布层面**不能被排除**，只是无法在现有数据上测量。其二，E3 测得两 suite 几乎无观测混叠（同任务高相似对的动作分歧率 0.24%~2.79%，随机对 47%~48%），按备注 6.1 预期注入量 $\approx 0$，与 E1-O 的零增益自洽；自洽不等于验证，正对照（构造混叠任务）待做。

## 7. 命题 6（算子类的表达力界）

前六节讲"信息在不在"与"信息何时兑现"，本节讲"算子取不取得到"。三者独立，任一失效都会表现为"加历史不变好"。

生产的轨迹打分为
$$\mathrm{TrajScore}(x) \;=\; \sum_{l=0}^{d-1} w_l \, s_l, \qquad s_l := \mathrm{Score}\big(\mathrm{anc}_l(x),\, q_{t-l}\big),$$
其中 $\mathrm{anc}_l$ 沿候选的祖先链回走 $l$ 步，$q_{t-l}$ 为 query 侧第 $l$ 个历史帧，且**配置校验强制 $w_l \ge 0$**（`src/openpi/cache/config.py`）。记该函数类
$$\mathcal{F}_d := \Big\{\, s \mapsto \textstyle\sum_{l} w_l s_l \;:\; w \in \mathbb{R}^d_{\ge 0} \,\Big\}.$$

打分链条含两次信息瓶颈：先把每层 $(q_{t-l}, \mathrm{anc}_l)$ 塌缩为边际相似度标量 $s_l$（标量化），再对 $\{s_l\}$ 施加非负可加组合（$\mathcal{F}_d$）。命题 6 的两部分分别刻画这两次瓶颈。

**命题 6.**

**(i) 标量化分离：帧间关系特征不是 $\{s_l\}$ 的函数.** 存在两组配置 $\{(q_{t-l}, \mathrm{anc}_l)\}_l$ 与 $\{(q'_{t-l}, \mathrm{anc}'_l)\}_l$，其逐层边际相似度向量 $\{s_l\}$ 完全相同，而帧间关系特征（如 $\cos\angle(\Delta q, \Delta \mathrm{anc})$，其中 $\Delta q := q_t - q_{t-1}$）取不同值。因此**任何** $\{s_l\}$ 的函数（可加与否、权重如何均然）都无法依赖此类特征；被标量化销毁的信息在下游不可恢复。

**(ii) 单调打分不能实现全局差分阈值.** 设某组固定其余坐标下 $(s_l, s_{l+1})$ 的定义域截面包含 $(0,1)^2$。对任意逐坐标单调不减的 $f$（特别地对一切 $f \in \mathcal{F}_d$，因 $\partial f/\partial s_i = w_i \ge 0$），不存在常数 $c$ 使
$$\mathbf{1}\{f(s) > c\} = \mathbf{1}\{s_l > s_{l+1}\}$$
对定义域中所有 $s$ 成立。即"匹配质量随时间改善还是恶化"这类需要对某个坐标作**负响应**的判别，在该类中不可实现。

**证明.** (i) 构造：单位向量取 $\mathrm{anc}_0 = (1,0)$，$\mathrm{anc}_1 = (0,1)$，$\theta = 30^\circ$，$R_\theta$ 为旋转。

- *配置一（同向旋转）*：$q_{t-l} = R_{+\theta}\,\mathrm{anc}_l$。则 $s_0 = s_1 = \cos\theta$，且 $\Delta q = R_{+\theta}\Delta\mathrm{anc}$，故 $\cos\angle(\Delta q, \Delta\mathrm{anc}) = \cos\theta \approx 0.866$。
- *配置二（交替旋转）*：$q_t = R_{+\theta}\mathrm{anc}_0,\ q_{t-1} = R_{-\theta}\mathrm{anc}_1$。逐层相似度仍为 $s_0 = s_1 = \cos\theta$，但 $\Delta q = (0.366, -0.366) \parallel (1,-1) = \Delta\mathrm{anc}$，故 $\cos\angle(\Delta q, \Delta\mathrm{anc}) = 1$。

两配置的 $\{s_l\}$ 逐值相同而特征值不同（$0.866 \ne 1$），故该特征不可测于 $\sigma(\{s_l\})$。

(ii) 固定其余坐标，取
$$x = (s_l, s_{l+1}) = (\tfrac34, \tfrac14), \qquad y = (\tfrac34, \tfrac9{10}).$$
有 $y \ge x$（逐坐标），单调性给出 $f(y) \ge f(x)$。但差分判别要求 $x$ 为正类（$s_l > s_{l+1}$）、$y$ 为负类（$s_l < s_{l+1}$），即 $f(x) > c \ge f(y)$，与 $f(y) \ge f(x)$ 矛盾。$\blacksquare$

**读法与边界.** 两部分合起来给出：生产打分链条**在结构上**取不到帧间动力学特征（(i)：进不了 $\{s_l\}$）与匹配质量趋势（(ii)：$\mathcal{F}_d$ 内无负响应），因此"搜索最优逐步权重形状"改变不了这两条不可表性；该搜索空间内的一切元素都只能以逐层边际相似度的非负组合排序。本命题**不**主张：每个 $w \in \mathcal{F}_d$ 都在做时间平滑（$w = (1,0,\dots,0)$ 就退化为单帧）；也不对未加定义的"dynamics-aware 函数类"作交集断言。可证的内容以 (i)(ii) 为准。

**本项目是否检验过？** ✓ 一致性签名：E1 的 C 组把差分特征 $[k_t, \Delta k_t, \Delta^2 k_t]$ 放到**特征层**（绕开标量化与 $\mathcal{F}_d$），$k=5$ 下取得 +9.25%~+12.42% 的残差降低；生产路径（$k=1$、$\mathcal{F}_d$、`top_k=1`）同一 cell 为 −1.74%~+8.80%。这与"信息存在于标量化之前的特征、现行算子取不到"的图景一致。不可表性本身由本节数学建立，实验提供的是签名而非证明。

## 9. 假设清单与本文**不**主张的东西

**依赖的假设**

- **A0（正则性）**：信息量良定有限；连续情形存在支配测度与正则条件分布。
- **A1（teacher 无记忆）**：$\pi_{0.5}$ 的架构事实；若换成带记忆的 backbone，引理 1 及其全部推论失效。
- **A2（key 是当前观测的函数）**：本系统的 key builder 满足；若 key 本身吃历史，$k_t$ 不再是 $o_t$ 的函数，引理 2 的证明失效。
- **命题 3 的 (4.1)**：不是定理，是一个**可检验的经验条件**；E1-O 在两个 suite 上给出与之一致的算子特定证据，不构成对它的证明，也不保证在别处成立。

**本文不主张**

1. **不主张 $I(a^*;h\mid k) = 0$。** 引理 2 明确允许它为正，E1 也测到与"为正"一致的证据。声称"历史无信息"是对本理论的误述。
2. **不主张"历史必然无用"，也不主张"历史必然有用"。** 命题 2.2 表明 A1、A2 下两个方向都不可推；答案由环境的时序耦合、key 与算子共同决定。
3. **不主张剂量-反应。** 备注 2.4 给出反例；"key 越弱历史越有用"是经验假说，且在本项目未被真正检验。
4. **不主张成功率天花板定理。** 从模仿误差到 rollout 回报需要额外假设，且 teacher 非最优（备注 5.2）。
5. **不主张固定算子上历史必然有害或必然无害。** 命题 4.2 表明符号在 A1、A2 下不确定，须由实验判定。
6. **不主张选择通道不存在，也不主张 success 过滤是唯一通道。** 命题 5 构造性地证明该类通道存在，备注 6.1 给出一般形式；本项目既未激活对它的测量，也不能排除上游筛选已经发生。
7. **不主张结论可迁移到别的 backbone / benchmark。** 全部实证来自 $\pi_{0.5}$ + LIBERO 两个 suite。
8. **不主张任何实验估计了互信息或贝叶斯风险的数值。** E1/E1-O 是固定 kNN 与欧氏残差下的算子特定证据；正结果按备注 5.1 的方向规则可作定性推断，零结果不能换读为"互信息为零"。

## 10. 一句话总结

$$\boxed{\;0 \;\le\; \underbrace{R^\star_{\log}(k_t) - R^\star_{\log}(k_t,h_t)}_{\text{历史带来的误差改善（对数损失）}} \;=\; I(a^*_t; h_t\mid k_t) \;\le\; \underbrace{I(a^*_t; o_t\mid k_t)}_{\text{key 的有损度}}\;}$$

**teacher 的条件独立结构决定了历史信息的来源与上界的形式；上界的数值由观测分布、teacher 映射与 key 共同决定；信息能否兑现为误差改善由损失决定；能否被系统兑现由算子决定。** 在本系统上，实测的历史信息落在上界内且数值很小；经阶段对齐后其可观测部分归零，与"历史携带的几乎全部是阶段坐标"一致（命题 3）；剩余部分落在现行算子类的表达力之外（命题 6）；而固定算子本身还可能被历史误导（命题 4.2），rollout 上表现为随 depth 的成功率退化。三者叠加，构成"加历史反而更差"的完整解释。历史的结构性正面通道只剩一条：选择条件化（命题 5），其正对照留待构造混叠任务的实验。
