## 0. 这份文档要回答的问题

一个 **training-free 的检索式 cache**：把 teacher policy 的 rollout 记成 `(key, action)` 条目，运行时用当前观测的 key 检索最近邻，直接复用其动作。

问题：**把历史帧纳入检索相似度，能否提升检索质量？**

直觉上"更多信息不会更差"。本文证明这个直觉在此系统中是错的，并给出信息量的**确切上界**：它由 teacher 的输入决定，而不是由环境或算法决定。

---

## 1. 设定与记号

| 符号 | 含义 |
|---|---|
| $o_t \in \mathcal{O}$ | $t$ 时刻的观测（图像 + 本体状态 + 语言指令） |
| $h_t \in \mathcal{H}$ | 历史，$h_t := (o_{<t}, a_{<t})$ |
| $\pi$ | teacher policy，**无记忆**：$a_t \sim \pi(\cdot \mid o_t)$ |
| $\xi_t$ | teacher 的内部采样噪声（flow-matching 的随机源） |
| $k: \mathcal{O} \to \mathcal{K}$ | key builder，**确定性且通常有损**；记 $k_t := k(o_t)$ |
| $a^*_t$ | **检索目标**：库中与观测 $o_t$ 配对存储的标签，即 $a^*_t = \pi(o_t; \xi_t)$ |
| $\mathcal{L} = \{(k(o^{(i)}), a^{*(i)})\}_i$ | 离线库 |

所有随机变量定义在同一概率空间上；$I(\cdot;\cdot\mid\cdot)$ 为条件互信息，$H$ 为（微分）熵。约定 $I \ge 0$，链式法则 $I(X; Y,Z \mid W) = I(X;Y\mid W) + I(X;Z\mid Y,W)$。

**假设 A1（teacher 无记忆）**
$$a^*_t = f(o_t, \xi_t), \qquad \xi_t \perp\!\!\!\perp (h_t, o_t).$$

> 这不是建模选择，而是对 $\pi_{0.5}$ 架构的陈述：它的前向只吃当前帧、本体状态与指令，不含任何跨时刻状态。采样噪声每次独立抽取，故 $\xi_t \perp h_t$。

**假设 A2（key 是观测的函数）**：$k_t = k(o_t)$，$k$ 确定性。

> 由构造成立：key builder 只吃当前帧。

---

## 2. 引理 1（标签条件独立）

**引理 1.** 在 A1 下，
$$\boxed{\,I(a^*_t \,;\, h_t \mid o_t) = 0\,}$$

**证明.** 由 A1，给定 $o_t = o$，
$$P(a^*_t \in \cdot \mid o_t = o,\, h_t = h) = P\big(f(o, \xi_t) \in \cdot \mid o_t=o,\ h_t=h\big) = P\big(f(o,\xi_t)\in\cdot\big),$$
最后一步用了 $\xi_t \perp (o_t, h_t)$。右端不依赖 $h$，故条件分布与 $h_t$ 无关，即 $a^*_t \perp h_t \mid o_t$，其条件互信息为零。$\blacksquare$

**读法.** 这是**继承定律的本体**：teacher 无记忆 ⇒ 它生成的标签在给定当前观测后与历史独立。证明本身平凡，重要的是它**限定了条件变量是完整观测 $o_t$**——下一节说明为什么这个限定不能省略。

**本项目是否检验过？** ✗ 未检验，也**无法**检验：估计 $I(a^*;h\mid o_t)$ 需要以完整观测为条件，而完整观测（原始图像）并未随库存储。本项目的所有实验都以 $k_t$ 为条件。

---

## 3. 引理 2（去噪上界）—— 本文的核心不等式

**引理 2.** 在 A1、A2 下，
$$\boxed{\,I(a^*_t \,;\, h_t \mid k_t) \;\le\; I(a^*_t \,;\, o_t \mid k_t)\,}$$

**证明.** 考虑联合量 $I(a^*_t; h_t, o_t \mid k_t)$，用链式法则两种展开。

*展开一（先 $o$ 后 $h$）*：
$$I(a^*_t; h_t, o_t \mid k_t) = I(a^*_t; o_t \mid k_t) + I(a^*_t; h_t \mid o_t, k_t).$$
由 A2，$k_t = k(o_t)$ 是 $o_t$ 的确定性函数，故以 $(o_t, k_t)$ 为条件等同于以 $o_t$ 为条件，于是第二项 $= I(a^*_t; h_t \mid o_t) = 0$（引理 1）。因此
$$I(a^*_t; h_t, o_t \mid k_t) = I(a^*_t; o_t \mid k_t). \tag{3.1}$$

*展开二（先 $h$ 后 $o$）*：
$$I(a^*_t; h_t, o_t \mid k_t) = I(a^*_t; h_t \mid k_t) + \underbrace{I(a^*_t; o_t \mid h_t, k_t)}_{\ge 0} \;\ge\; I(a^*_t; h_t \mid k_t). \tag{3.2}$$

合并 (3.1)(3.2) 即得。$\blacksquare$

**读法.** 右端 $I(a^*; o \mid k)$ 是**"给定 key 之后，完整观测还能补充多少关于标签的信息"**，即 **key 的有损度**。于是：

> **历史在检索中能贡献的信息量，被 key 丢失的信息量从上方封死。**

三条直接推论：

- **(a) key 充分 ⇒ 历史无用.** 若 $k$ 对 $a^*$ 充分（$I(a^*; o \mid k) = 0$），则 $I(a^*; h \mid k) = 0$，历史严格无增量。
- **(b) 剂量-反应.** $I(a^*;h\mid k)$ 随 key 退化而增大——这正是 rescue-the-weak 现象（弱 key 上历史 +10~21pp、强 key 上为负）的定理化。
- **(c) 历史的角色是"补 key 之失"，不是"引入新通道".** 任何 $I(a^*;h\mid k) > 0$ 的观测都**不是**对继承定律的反例；它恰好是引理 2 允许的范围。

**本项目是否检验过？** ✓ E1 直接估计左端。实测为正：spatial 的 B-d3 相对残差降低 +5.35%、C-g1.0 +8.80%，libero_10 的 B-d3 +2.86%（Holm 调整后区间下界均 > 0）。**这与引理 2 一致，不构成对理论的削弱。**

## 4. 命题 3（阶段吸收）—— E1-O 的形式化

引理 2 只给上界，不说明左端由**哪个维度**贡献。下面把"历史其实只在编码阶段"这一断言形式化。

设 $\phi_t$ 为**阶段变量**（本项目取归一化进度 $\phi_t = c_t / (C-1)$，$c_t$ 为 episode 内 inference cycle 序号、$C$ 为总 cycle 数）。注意 $\phi_t$ 是 $o_{\le t}$ 的函数但**不是** $k_t$ 的函数——pooled 视觉 key 不含 cycle 索引。

**命题 3.** 若
$$I(a^*_t \,;\, h_t \mid k_t,\ \phi_t) = 0, \tag{4.1}$$
则
$$I(a^*_t; h_t \mid k_t) \;\le\; I(a^*_t; \phi_t \mid k_t),$$
且历史的全部增量可由阶段变量替代：任何以 $(k_t, h_t)$ 为输入的预测器，其可达的最小期望损失不低于以 $(k_t,\phi_t)$ 为输入者。

**证明.** 与引理 2 同构。展开
$$I(a^*; h,\phi \mid k) = I(a^*; \phi\mid k) + \underbrace{I(a^*; h \mid \phi, k)}_{=0 \text{ 由 }(4.1)} = I(a^*;\phi\mid k),$$
又
$$I(a^*; h,\phi\mid k) = I(a^*; h\mid k) + \underbrace{I(a^*;\phi\mid h,k)}_{\ge 0} \ge I(a^*;h\mid k).$$
合并即得不等式。后半句由数据处理不等式与充分性直接给出。$\blacksquare$

**本项目是否检验过？** ✓ **E1-O 正是 (4.1) 的检验**：把候选池限制到 $|\phi(\text{query}) - \phi(\text{candidate})| \le \varepsilon$，即近似地"给 key 补上阶段维度"，再看历史是否还有增量。

实测（8 个 cell = 2 suite × 2 个 $\varepsilon$ × 2 个 depth）：**无一支持历史有增量**；libero_spatial 在 $\varepsilon=0.05$ 下相对增益为**精确的 0.00%**。且已验证候选池未退化（对齐后中位 8–20 个候选，最小 3 个，无一退化到 $\le 1$）——否则"零增益"会是候选集塌缩的伪影而非信息论事实。

⇒ 在本系统上，$I(a^*;h\mid k) \approx I(a^*;\phi\mid k)$：**历史携带的几乎全部是阶段信息**。

## 5. 定理 4（模仿误差下界；历史有用的充要条件）

前三节讲信息，本节把它接到**可达的误差**上。

设检索系统输出 $\hat a_t = g(k_t, h_t)$，$g$ 为任意可测函数（这覆盖了任何检索 + 加权组合的实现）。设损失 $\ell(\hat a, a^*) \ge 0$。

**定理 4.** 记
$$R^\star(\mathcal{S}) := \inf_{g \text{ 可测}} \mathbb{E}\big[\ell\big(g(\mathcal{S}),\, a^*_t\big)\big]$$
为以变量集 $\mathcal{S}$ 为输入时的**贝叶斯风险**。则
$$R^\star(k_t, h_t) \le R^\star(k_t),$$
且当损失为对数损失时，两者之差恰为
$$R^\star(k_t) - R^\star(k_t, h_t) = I(a^*_t; h_t \mid k_t).$$
特别地：
$$\boxed{\,\text{历史能降低模仿误差} \iff I(a^*_t; h_t \mid k_t) > 0\,}$$

**证明.** 单调性 $R^\star(k,h) \le R^\star(k)$ 由"更大的信息集不减小可达最优"直接得到（任何只用 $k$ 的 $g$ 都是同时用 $(k,h)$ 的一个特例）。

对数损失下，贝叶斯风险即条件熵：$R^\star(\mathcal{S}) = H(a^*_t \mid \mathcal{S})$。故
$$R^\star(k) - R^\star(k,h) = H(a^*\mid k) - H(a^*\mid k,h) = I(a^*; h\mid k). \qquad\blacksquare$$

**与引理 2 合并**，得到本文的**主定理形式**：

> **推论 4.1（继承定律的可操作形式）**
> $$0 \;\le\; R^\star(k_t) - R^\star(k_t, h_t) \;=\; I(a^*_t; h_t\mid k_t) \;\le\; I(a^*_t; o_t \mid k_t).$$
> 即：**在检索式 cache 中，引入历史所能带来的模仿误差改善，不超过 key 相对完整观测的信息损失。teacher 无记忆把这条上界钉死，与环境是否 POMDP 无关。**

**关于"成功率天花板"的诚实说明.** 从模仿误差推到 rollout 成功率需要额外假设（例如 obs-MDP + 误差到回报的单调性），且 teacher 本身并非最优策略——检索误差偶然改善回报在原则上不能排除。**本文不声称成功率意义上的天花板定理**；纪要 §13 的"定理 3"在此降格为条件性陈述，其严格化留待后续。

**本项目是否检验过？** ✓ E1 用与生产同构的 kNN 估计 $R^\star$ 的可达值（生产为 `top_k=1` 的加权相似度检索），因此测的是"这一类算子上历史能否降低误差"，而非"任何算子上"。

## 6. 命题 5（例外通道：success 过滤是 collider 条件化）

引理 1 的结论 $I(a^*;h\mid o)=0$ 有一个**结构性例外**：若库在构建时按 episode 成功与否做过筛选，则条件化在一个 collider 上，可以**重新注入**历史信息。

设 $Z \in \{0,1\}$ 为 episode 成功指示。因果结构上 $Z$ 同时受 $h_t$（历史决定了真实分支）与 $a^*_t$（当前动作对不对）影响，故 $Z$ 是 $h_t \to Z \leftarrow a^*_t$ 的对撞点。条件化在 $Z=1$ 上会打开这条路径。

**命题 5.** 存在满足 A1 的模型，使得
$$I(a^*_t; h_t \mid o_t) = 0 \quad\text{但}\quad I(a^*_t; h_t \mid o_t,\ Z=1) = 1 \text{ bit}.$$

**证明（构造 + 闭式计算）.** 两分支观测混叠任务：

- 隐藏分支 $B \in \{\mathrm{L}, \mathrm{R}\}$，$P(B=\mathrm{L}) = 1/2$；
- 观测 $o$ 对两分支**完全相同**（混叠），故 $o \perp B$；
- 历史 $h$ **完全决定** $B$（例如开局时看到过路标）；
- 正确动作依赖分支：分支 $\mathrm{L}$ 下正确动作为 $a_\mathrm{L}$，分支 $\mathrm{R}$ 下为 $a_\mathrm{R}$，$a_\mathrm{L}\ne a_\mathrm{R}$；
- teacher 无记忆，只见 $o$，故只能均匀猜：$a^* \sim \mathrm{Unif}\{a_\mathrm{L}, a_\mathrm{R}\}$，且 $a^* \perp B$（满足 A1）；
- 成功当且仅当动作与分支匹配：$Z = \mathbf{1}\{(B,a^*) \in \{(\mathrm{L},a_\mathrm{L}), (\mathrm{R},a_\mathrm{R})\}\}$。

*未过滤*：$a^* \perp B$ 且 $h$ 只通过 $B$ 影响一切，故给定 $o$ 有 $a^* \perp h$，即 $I(a^*;h\mid o) = 0$，teacher 成功率 $P(Z=1) = 1/2$。

*条件在 $Z=1$*：此时 $(B, a^*)$ 只能取 $(\mathrm{L},a_\mathrm{L})$ 或 $(\mathrm{R},a_\mathrm{R})$，各以 $1/2$ 出现。于是给定 $Z=1$，$a^*$ 由 $B$ 唯一决定，而 $h$ 唯一决定 $B$：
$$H(a^*\mid o, Z=1) = 1 \text{ bit}, \qquad H(a^*\mid o, h, Z=1) = 0,$$
故 $I(a^*; h \mid o, Z=1) = 1$ bit。$\blacksquare$

**含义.** 在 **success 过滤的库**上，检索若能用历史匹配到"同分支"的条目，成功率可由 50% 提升到 100%。这是历史在本框架内**唯一**的正面通道，也是"记忆假肢"实验要构造的正对照。

**本项目是否检验过？** ✗ **未检验**，且在本数据上**未被激活**：

- 所用 artifact 的每个条目 `outcome = None`（未标注成功/失败），检索路径亦未启用 `QueryFilter.outcome`（`extra_filter_outcome=None`）；
- 因此若库在构建时做过 success 筛选，本实验既无法确认、也无法测量其效应；
- LIBERO 近似 obs-MDP ⇒ 真实的观测混叠分支稀少 ⇒ 预期重注量 $\approx 0$，这与 E1-O 的零增益自洽，但**自洽不等于验证**。

## 7. 命题 6（算子类的表达力界）

前六节讲"信息在不在"，本节讲"算子取不取得到"——两者独立，缺一即导致"加历史反而更差"。

生产的轨迹打分为
$$\mathrm{TrajScore}(x) \;=\; \sum_{l=0}^{d-1} w_l \, s_l, \qquad s_l := \mathrm{Score}\big(\mathrm{anc}_l(x),\, q_{t-l}\big),$$
其中 $\mathrm{anc}_l$ 沿候选的祖先链回走 $l$ 步，$q_{t-l}$ 为 query 侧第 $l$ 个历史帧，且**配置校验强制 $w_l \ge 0$**（`src/openpi/cache/config.py`）。

记该函数类
$$\mathcal{F}_d := \Big\{\, s \mapsto \textstyle\sum_{l} w_l s_l \;:\; w \in \mathbb{R}^d_{\ge 0} \,\Big\}.$$

**命题 6.** 对任意 $f\in\mathcal{F}_d$：

1. **无跨时刻交互**：$\dfrac{\partial^2 f}{\partial s_i \partial s_j} = 0$ 对一切 $i \ne j$；
2. **逐坐标单调不减**：$s_i \le s_i' \Rightarrow f(\dots,s_i,\dots) \le f(\dots,s_i',\dots)$；
3. **差分核不可表**：任何形如 $\mathrm{sgn}(s_l - s_{l+1})$ 的判别（"匹配质量随时间改善还是恶化"）都不能由 $\mathcal{F}_d$ 中任何元素的水平集实现。

**证明.** (1) $f$ 对 $s$ 是线性的，二阶混合偏导为零。

(2) $\partial f/\partial s_i = w_i \ge 0$。

(3) 反证：若某 $f\in\mathcal{F}_d$ 的水平集能区分 $s_l > s_{l+1}$ 与 $s_l < s_{l+1}$，考虑两点
$$s^{(1)} = (\dots, s_l = 1,\ s_{l+1} = 0, \dots),\qquad s^{(2)} = (\dots, s_l = 0,\ s_{l+1} = 1, \dots),$$
其余坐标相同。则 $f(s^{(1)}) - f(s^{(2)}) = w_l - w_{l+1}$。要让该差在"改善"与"恶化"两侧异号，需要 $w_l - w_{l+1}$ 同时取正负，不可能；若要用单个 $f$ 把两者分到水平集两侧，需 $w_l - w_{l+1} \ne 0$ 且方向可选，但由 (2) 两个权重都非负，$f$ 关于**每一个** $s_l$ 都单调不减——因此 $f$ 无法对"$s_{l+1}$ 增大"给出负响应，而差分判别恰恰要求这一点。$\blacksquare$

**推论 6.1.** 逐帧标量化（先把每帧塌缩成边际相似度 $s_l$）已经销毁了 key 向量层面的时间结构（如 $\Delta q_t$ 与 $\Delta\,\mathrm{anc}$ 是否同向）；再加非负可加组合，$\mathcal{F}_d$ 退化为**边际相似度上的低通平滑核**。因此"搜索最优逐步权重形状"是在一个**与 dynamics-aware 打分交集为空**的函数类内部搜索——空集结果由算子类预先决定，与数据无关。

**本项目是否检验过？** ✓ 间接但直接相关：E1 的 **C 组**把差分特征 $[k_t, \Delta k_t, \Delta^2 k_t]$ 放到**特征层**（绕过 $\mathcal{F}_d$ 的限制），在 $k=5$ 下取得 +9.25%~+12.42% 的残差降低；而生产的 $k=1$ + $\mathcal{F}_d$ 路径下同一 cell 仅 −1.74%~+8.80%。**信息在特征里，算子取不到**——这正是命题 6 的实证签名。

## 9. 假设清单与本文**不**主张的东西

**依赖的假设**

- **A1（teacher 无记忆）**：$\pi_{0.5}$ 的架构事实；若换成带记忆的 backbone，引理 1 及其全部推论失效。
- **A2（key 是当前观测的函数）**：本系统的 key builder 满足；若 key 本身吃历史，$k_t$ 不再是 $o_t$ 的函数，引理 2 的证明失效。
- **命题 3 的 (4.1)**：不是定理，是一个**可检验的经验条件**；E1-O 在本系统的两个 suite 上支持它，不保证在别处成立。

**本文不主张**

1. **不主张 $I(a^*;h\mid k) = 0$。** 恰恰相反，引理 2 明确允许它为正，E1 也确实测到为正。声称"历史无信息"是对本理论的误述。
2. **不主张成功率天花板定理。** 从模仿误差到 rollout 回报需要额外假设，且 teacher 非最优（见 §5 末）。
3. **不主张 collider 通道不存在。** 命题 5 构造性地证明了它存在；本项目只是既未激活也未测量它。**这是把"负结果"升级为"完整刻画"所缺的关键正对照。**
4. **不主张结论可迁移到别的 backbone / benchmark。** 全部实证来自 $\pi_{0.5}$ + LIBERO 两个 suite。
5. **不主张剂量-反应（推论 (b)）已被验证。** 本项目的 6 个 key builder 在质量代理上跨度仅 2.6%~7.5%，自变量无动态范围，该检验**未被真正执行**（见 `analysis/e1_residual.md` §8）。

## 10. 一句话总结

$$\underbrace{R^\star(k_t) - R^\star(k_t,h_t)}_{\text{历史带来的误差改善}} \;=\; I(a^*_t; h_t\mid k_t) \;\le\; \underbrace{I(a^*_t; o_t\mid k_t)}_{\text{key 的有损度}}$$

**teacher 的输入决定了一切派生检索系统能从历史中榨取的信息上界。** 在本系统上，这个上界不仅小，而且经 E1-O 定位后发现它**几乎全部来自阶段维度**——阶段一旦直接对齐即归零；剩下的部分又因命题 6 而落在现行算子类之外。三者叠加，才是"加历史反而更差"的完整解释。

## 11. 数学审阅附录（2026-08-14）

> **审阅说明。** 本节是对上文的独立数学审阅，不改写原文，目的是区分三件不同的事：
>
> 1. A1、A2 本身严格蕴含什么；
> 2. 一个 Bayes 最优预测器能否利用历史；
> 3. 当前有限库、固定相似度和固定 kNN 算子能否利用历史。
>
> 审阅结论是：**引理 1、引理 2 正确，而且引理 2 的上界可取到；但 A1、A2 不足以证明“历史必然有用”或“历史必然无用”。对于现行固定检索算子，加入历史既可能改善，也可能恶化。** 原文关于剂量-反应、一般损失、阶段等号、实验对互信息的估计，以及命题 6 的若干外推需要收窄。

### 11.1 核心问题在 A1、A2 下不可作统一的是/否回答

为简化记号，本节写 $A=a_t^*$、$O=o_t$、$H=h_t$、$K=k_t$。考虑核心问题：

> 把历史 $H$ 纳入输入或检索相似度，是否必然提高检索质量？

仅凭 A1、A2，答案既不是恒真也不是恒假。

**定理 7（双向非蕴含与上界的紧性）.** 在 A1、A2 下：

1. 存在模型使 $I(A;H\mid K)=0$；
2. 存在模型使
   $$I(A;H\mid K)=I(A;O\mid K)=1\text{ bit};$$
3. 因而 A1、A2 既不能推出“历史无增量”，也不能推出“历史有正增量”；引理 2 的上界在允许的模型类中是紧的。

**证明.** 取二元状态 $B\sim\mathrm{Bernoulli}(1/2)$，teacher 为确定性的无记忆策略 $A=O$，key 为常数 $K=0$。这满足 A1、A2。

- **零增量模型**：环境各时刻的状态独立同分布，令 $O_t=B_t$，历史只含独立的 $B_{<t}$。于是 $A_t=B_t$ 与 $H_t$ 独立，故 $I(A;H\mid K)=0$。
- **满增量模型**：环境在整个 episode 保持同一个隐藏分支 $B$，令 $O_t=B$，且过去观测已经把 $B$ 写入 $H_t$。于是 $A=B=H$，而 $K$ 为常数，所以
  $$I(A;H\mid K)=H(A)=1\text{ bit},$$
  同时 $A$ 是 $O$ 的确定性函数，故
  $$I(A;O\mid K)=H(A)=1\text{ bit}.$$

两模型使用相同的无记忆 teacher 和相同的 key builder，只改变环境产生的时序联合分布，却得到两个相反答案。$\blacksquare$

这个构造还说明：“teacher 输入决定上界”只能理解为 **teacher 的条件独立结构决定上界的形式**。上界的数值 $I(A;O\mid K)$ 仍由观测分布、teacher 映射和 key builder 共同决定；实际历史增量还依赖环境如何把 $H$ 与 $O$ 关联起来。

### 11.2 对固定非负加性 1-NN，历史可以改善也可以恶化

Bayes 风险的“更多信息不更差”不能直接套到一个固定有限样本检索器。考虑两个候选 $G$（动作正确）与 $B$（动作错误），生产式打分为

$$S(x)=s_0(x)+\lambda s_1(x),\qquad \lambda=0.2,$$

并取最大分候选。

**历史使结果变差的构造：**

| 候选 | 当前相似度 $s_0$ | 历史相似度 $s_1$ | 总分 |
|---|---:|---:|---:|
| 正确候选 $G$ | $1.0$ | $0.0$ | $1.0$ |
| 错误候选 $B$ | $0.9$ | $1.0$ | $1.1$ |

只用当前帧会选 $G$；加入历史后改选 $B$。

**历史使结果改善的构造：**

| 候选 | 当前相似度 $s_0$ | 历史相似度 $s_1$ | 总分 |
|---|---:|---:|---:|
| 正确候选 $G$ | $0.9$ | $1.0$ | $1.1$ |
| 错误候选 $B$ | $1.0$ | $0.0$ | $1.0$ |

只用当前帧会选 $B$；加入历史后改选 $G$。这些数值可由二维或三维单位向量的余弦相似度实现，标签也可由一个确定性的无记忆 teacher 生成，因此不与 A1、A2 冲突。

所以，对固定检索器而言，“加入历史后的误差变化符号”不是信息论定理；它同时取决于有限库的几何、权重、tie-breaking、候选覆盖和标签分布。

### 11.3 引理 2 正确，但“剂量-反应”不是其推论

引理 2 只说明 key 退化时**可能的上界变松**，不说明 $I(A;H\mid K)$ 本身单调增加。条件互信息通常不随条件变量的信息量单调变化。

**反例.** 令 $X,Y$ 为独立均匀二元变量，

$$O=(X,Y),\qquad A=X,\qquad H=Y.$$

取较强 key $K_s=X\land Y$，再把它退化成常数 key $K_w=0$。显然 $K_w$ 是 $K_s$ 的确定性 garbling，并且两者都满足 A2；$A$ 是 $O$ 的函数，故 A1 也成立。记 $h_2$ 为二元熵，则

$$I(A;O\mid K_s)=\frac34 h_2\!\left(\frac13\right)\approx0.6887\text{ bit},$$

而

$$I(A;H\mid K_s)=\frac34 h_2\!\left(\frac13\right)-\frac12\approx0.1887\text{ bit}.$$

退化为常数 key 后，

$$I(A;O\mid K_w)=H(A)=1\text{ bit},\qquad I(A;H\mid K_w)=I(X;Y)=0.$$

因此 key 的 label-relevant 有损度从 $0.6887$ 增到 $1$ bit，历史条件互信息却从 $0.1887$ 降到 $0$。正文 §3(b) 只能作为待检验的经验假说，不能列为引理 2 的直接推论。

### 11.4 命题 3 的不等式成立，但近似等号需要额外条件

若

$$I(A;H\mid K,\Phi)=0,$$

则正文证明的

$$I(A;H\mid K)\le I(A;\Phi\mid K)$$

成立，而且有更精确的恒等式

$$I(A;\Phi\mid K)-I(A;H\mid K)=I(A;\Phi\mid K,H)\ge0. \tag{11.1}$$

所以从 (4.1) 本身不能推出

$$I(A;H\mid K)\approx I(A;\Phi\mid K).$$

要得到等号或近似等号，还需 $I(A;\Phi\mid K,H)=0$ 或近似为零。一个充分条件是 $\Phi$ 可由 $(K,H)$ 确定。

严格反例是：令 $K$ 为常数，$A=\Phi\sim\mathrm{Bernoulli}(1/2)$，$H=\Phi\oplus N$，其中 $N\sim\mathrm{Bernoulli}(p)$ 独立且 $0<p<1/2$。此时

$$I(A;H\mid K,\Phi)=0,$$

但

$$I(A;H\mid K)=1-h_2(p)<1=I(A;\Phi\mid K).$$

命题 3 关于任意损失的风险比较可以保留，但需要补上 Blackwell 论证：由 $A\perp H\mid(K,\Phi)$，可从 $(K,\Phi)$ 用与 $A$ 无关的核 $P(H\mid K,\Phi)$ 模拟 $(K,H)$，所以 $(K,H)$ 是 $(K,\Phi)$ 的 garbling；在通常的可测性条件下，任意决策损失均有

$$R_\ell^*(K,\Phi)\le R_\ell^*(K,H).$$

另外，本项目实际使用的

$$\Phi_t=\frac{c_t}{C-1}$$

含 episode 的最终总 cycle 数 $C$。若 $C$ 不是预先固定且在线已知，则 $\Phi_t$ 不是 $o_{\le t}$ 或 $H_t$ 的函数，而是使用未来信息的离线 oracle。它仍可用于描述性对齐，但可能同时编码终止时间或成功信息；因此 E1-O 不能在不加假设时被解释为只“补上一个在线阶段坐标”。

### 11.5 定理 4 的等号与充要条件只属于对数损失

对任意损失，始终成立的只有

$$R_\ell^*(K,H)\le R_\ell^*(K),$$

以及

$$I(A;H\mid K)=0\quad\Longrightarrow\quad R_\ell^*(K,H)=R_\ell^*(K).$$

反方向对一般损失不成立。令 $K$ 为常数、$H\sim\mathrm{Bernoulli}(1/2)$，并令

$$P(A=1\mid H=0)=0.8,\qquad P(A=1\mid H=1)=0.9.$$

因为两个条件分布不同，所以 $I(A;H)>0$；但在 0-1 损失下，无论是否观察 $H$，Bayes 决策都恒为 $1$，两边风险都等于

$$\frac12(0.2+0.1)=0.15.$$

同一例子对一维绝对误差也成立。因此

$$I(A;H\mid K)>0$$

并不是任意 imitation loss 下风险严格降低的充分条件。

若预测器输出的是条件概率分布 $q(\cdot\mid S)$，损失明确取对数评分

$$\ell_{\log}(q,A)=-\log q(A),$$

且所有条件熵或 KL 量有限，则正文的等号正确：

$$R_{\log}^*(K)-R_{\log}^*(K,H)=I(A;H\mid K). \tag{11.2}$$

连续动作情形还需指定共同支配测度和条件密度；此时负对数密度未必非负，因此正文同时假设 $\ell\ge0$ 与微分熵并不完全相容。

据此，正文主公式的严格版本应写成

$$\boxed{
0\le R_{\log}^*(K)-R_{\log}^*(K,H)
=I(A;H\mid K)
\le I(A;O\mid K)
} \tag{11.3}$$

并在每次引用时保留“对数损失、分布值预测器、量有限”的限定。

### 11.6 E1/E1-O 不能直接估计上述互信息或 Bayes 风险

E1 使用固定 kNN 和欧氏动作残差，而不是对数评分。因此它估计的是一个**特定有限样本算子的经验风险差**，不是

$$I(A;H\mid K),$$

也不是对所有可测预测器取下确界的 $R^*$。残差百分比与 bit/nat 也没有可直接相等的量纲关系。

同理，E1-O 在候选池上施加 $|\Phi_q-\Phi_c|\le\varepsilon$ 的硬窗口，再比较两个固定打分器；这可以作为“阶段对齐后，该算子的历史增益是否仍可观测”的实验，但不是条件独立

$$A\perp H\mid(K,\Phi)$$

的直接检验。尤其在等价性检验未成立时，“未支持正增益”不能替换成“互信息为零”。正文 §3、§4、§8 中的“直接估计左端”“检验 (4.1)”和“估计 $R^*$”均应改为“与理论一致的算子特定证据”。

### 11.7 命题 6(3) 的结论可在精确定义后证明，但原证明不成立

正文使用 $(1,0)$ 与 $(0,1)$ 两点的证明不充分：取 $w_l>w_{l+1}$ 就能把这两个点正确排序。要证明的是全定义域上的不可表示性，而不是只比较这一对点。

一个可证明的严格版本如下。

**命题 8（非负单调打分不能实现全局差分阈值）.** 假设存在一组固定的其余坐标，使 $(s_l,s_{l+1})$ 的相应定义域截面包含 $[0,1]^2$。对任意逐坐标单调不减函数 $f$，不存在常数 $c$ 使

$$\mathbf 1\{f(s)>c\}=\mathbf 1\{s_l>s_{l+1}\}$$

对定义域中所有 $s$ 成立。因而该结论特别适用于 $f(s)=\sum_iw_is_i$、$w_i\ge0$。

**证明.** 固定其余坐标，取

$$x=(s_l,s_{l+1})=(3/4,1/4),\qquad y=(3/4,1).$$

有 $y\ge x$（逐坐标），所以单调性给出 $f(y)\ge f(x)$。但差分判别要求 $x$ 为正类、$y$ 为负类；任何超水平集 $\{f>c\}$ 都不可能同时满足这两个要求。$\blacksquare$

这只证明了“需要对某个相似度坐标作负响应的全局差分阈值不可表达”。它不能进一步推出：

- 任意非负权重都是低通核；例如 $(1,0,\ldots,0)$ 并不执行时间平滑；
- $\mathcal F_d$ 与所有 dynamics-aware 打分的交集为空；
- 某次 C 组或 $k=5$ 的改善直接验证了函数类不可表示性。

这些更强结论需要先给出 dynamics-aware 函数类的精确定义和独立的函数类分离证明。

### 11.8 success filtering 是一种 collider 通道，不是唯一通道

命题 5 的构造和 1 bit 计算是正确的，但它只证明 success filtering **可以**重新注入历史依赖，没有证明其唯一性。一般地，只要选择变量 $S$ 的条件概率 $P(S\mid A,H,O)$ 同时依赖 $A$ 与 $H$，即使原分布满足 $A\perp H\mid O$，条件分布中也可能有

$$I(A;H\mid O,S=1)>0.$$

success、人工筛选、删失、按未来回报加权等都属于这类机制。更准确的表述应是“success filtering 是一个明确且重要的正面通道”。另外，artifact 的 `outcome=None` 只能说明没有可用 outcome 字段，不能单独排除 artifact 在更上游已由成功轨迹筛选。

### 11.9 最终数学判定

可以严格证明的结论是：

1. **结构定理成立**：A1、A2 蕴含
   $$I(A;H\mid K)\le I(A;O\mid K).$$
2. **上界是紧的**：存在满足 A1、A2 的模型取等号。
3. **充分 key 排除 Bayes 意义的历史增量**：若 $I(A;O\mid K)=0$，则 $I(A;H\mid K)=0$。
4. **有损 key 不保证历史有用**：右端为正时，左端仍可为零。
5. **在对数损失的 Bayes 最优意义下**，历史改善严格等于条件互信息。
6. **在当前固定检索算子下**，A1、A2 对改善符号没有结论；历史可能改善、无影响或恶化。

因此，核心问题“加入历史能否提升检索质量”的严格回答是：

> **能，但不必然；也可能变差。teacher 无记忆只限制了历史信息的来源和上界，没有决定特定检索器上的效果符号。要判定本系统的符号与大小，仍必须依赖算子特定的实验或增加更强的分布、充分性与一致性假设。**
