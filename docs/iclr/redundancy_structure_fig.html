Figure（草案）：可回收冗余的时间结构。(a) LIBERO-10 fh40_ws40 的 8 条真实 episode，蓝=回放、灰=推理；(b) 全部 7 个 config 的 P(hit|hit) vs P(hit)，虚线为独立基线；(c) 命中段长度生存曲线（log-y），点线为各自边际命中率下的几何分布基线。

三个 panel 各自的一句话

(a) 定性

冗余不是撒在轨迹里的噪声，是成段的"套路化子轨迹"——一眼看见块。

(b) 收纳所有 config

不逐个讲 config：每个 config 折叠成一个点，7 点全部远离独立对角线（+0.24 ~ +0.63）。操作点无关的普遍现象。

(c) 定量反事实

实测命中段比独立假设长 2–3 个数量级（P90 达 18–52 步 vs 几何基线几步内衰完）。

正文讲法（建议三句话 + 一个数字段）

  • 句 1：命中不独立——进入已示范区段后持续命中（P(hit|hit) 0.91–0.96，全操作点）。
  • 句 2：因此可回收冗余以块的形态出现，中位 9–12 步、一成的段超过 40 步（LIBERO-10）。
  • 句 3：块内 93–98% 的检索持续跟随同一条库轨迹（lockstep）——系统在"认出这段经历后整段接管"，而非逐步拼贴。lockstep 纯度随阈值放宽而下降（Δ+1 率 0.92→0.69），作次级观察入脚注或附录。

裁决点

  • 图 vs 表：图——(b) 把"7 个 config"问题消掉了；表只在附录放逐 config 数字。
  • (a) 的代表 config 选哪个：建议与 §5.1 主操作点一致（fh40_ws40），审稿人无从质疑挑样。
  • lockstep 是否单独一个 panel：当前并入文字；若 §5.3 篇幅够，可加第四 panel 画"命中段内 winner 的 (轨迹, 步) 阶梯图"。
