\paragraph{Experiment list.}

claim the experiment supports. Status: \DONE\ = analyzed; \INHAND\ = collected, analysis pending
re-framing; \RUNNING\ = currently executing; \STALE\ = old data from a
superseded configuration, to be re-collected; \TORUN\ = not started.
