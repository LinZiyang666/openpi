## 分模型结论

- **Fast-WAM-LIBERO**：模型侧接入是忠实的。分段切点、预处理、toggle、相机顺序、state 布局、prompt、H32 都与 vendor 和发布版 processor 一致，CPU stub 上 staged 与原 loop 逐位一致。但 LIBERO 的 benchmark 侧没接上 R17：没有 ack，commit 会静默降级（B1）；没有 request 身份，init、suite、task 都被混淆（B2）；没有 R17 conductor/strategy。key 成本里多了 T5（B4）；默认协议也不是发布版的评测协议（B6）。**结论：GPU 资格通过后可以跑 plain full 和 K 档基线；commit、五层、逐任务下降在 LIBERO 上目前不可用。**
- **Fast-WAM-MW**：与 C 的服务路径逐位对应，包括 A 的正式 seed 规则。P2 runner 提供 ack 和 request context，commit、tail、五层（P1 recipe）和 debug 采集都接得上。主要问题是 stage1 里的 T5（B4）：在 MISS 成本最低的 MW（49 token）上，Ckey 占比最高。**结论：接入正确；在给出任何缓存成本结论之前必须先修 B4。** 仍待：immutable 最终 checkpoint、GPU parity、计价、真实库。
- **DP-LIBERO**：staged 与 E 在 CPU 上逐位一致，真实 checkpoint 也已 strict load；两次反归一化顺序正确。但它也受 B1、B2 的影响，K1 不可用（B3），生产入口没有 recipe/capture（B8），两视角证据是合成的（B11）。**结论：K100 和 K2 的 plain 基线可用；K1、commit、五层在 LIBERO 上不可用。**
- **DP-MW**：与 E 逐位一致，包括正式 seed 规则；P2 runner 的路径已在 CPU 上走通。K1 不可用（B3），生产入口没有 recipe/capture（B8）。现在只有 ML45 的诊断 checkpoint，最终 MT50 export 还没有。**结论：K100、K2，以及通过 factory API 的五层和 debug 可用；必须先去掉 K1；正式结果要等 MT50 export。**

## INVENTORY 中仍不支持的功能

**四个模型都缺**（通用执行器明确拒绝，或者没有为新模型接线、只有 CPU 证据）：S04/S05 副本代理未对这些模型做资格；S06/S07 的 B>1 只在 CPU 上验证过，GPU 数值和显存未 qualified；S13 stage1-only、compile、分设备放置没有实现；P04 只允许 `always_hit/always_miss/threshold` judge，其余 judge 族和 warm tier 都被拒；P13 WARM_START（native resume 只有直接 API，没有 stock 派发）；P14 warm-reset/self-start；P15 CP2/online-RIT/shadow/routing；P16；D01 PolicyRecorder；D02 旧 DataCollector H5（由 P6 capture 代替）；D03/D04 staged trace serving 和 twins（`trace.enabled` 被拒）；D07 look recording；D10 增广只有 hook，没有调度和 loader 接线；D12 warmup factor dump/calibration；D13/D14 尚未构建真实 teacher 库；A01 没有真实价格；X01 split 不支持。

**Fast-WAM-LIBERO 另缺**：P11/P12 commit/tail（B1）；P05/P07/P08 需要正确 task/init 身份的部分，包括 per-task 库、corrector one-hot、periodic coin（B2）；P09 逐任务下降和 C01–C05 的 R17 派发、兼容性、attestation（没有 LIBERO strategy、worker entry、BenchmarkSpec）；D05/D08 的 execution 状态永远停在 pending_ack；D09 新模型下的 LIBERO 物理采集未验证；W01 的参考协议（n_action_steps=32、256 原帧）无法复现（B6）。

**Fast-WAM-MW 另缺**：没有超出通用项的功能缺失；但 HIT 的成本收益要等 B4 修复和 GPU 计价才能确定，正式资格还要等 immutable 的 MT50 export。

**DP-LIBERO 另缺**：与 Fast-WAM-LIBERO 相同的 LIBERO 项（P11/P12、P05/P07/P08 身份、P09、C01–C05、D05/D08 ack、D09）；P10 的 K1（B3）；生产入口的五层和 debug（B8）；两个真实视角 key 的实帧证据（B11）。

**DP-MW 另缺**：P10 的 K1（B3）；生产入口的五层和 debug（B8）；正式 MT50 checkpoint（目前 ML45 85k 只是诊断用的）。
