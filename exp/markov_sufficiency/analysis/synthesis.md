## 1. 要判别的是什么

出发点是一个反直觉的观测：在 trajectory 线上，**把历史帧纳入检索相似度（`trajectory_depth > 1`）会让成功率下降**，libero_spatial 上最深达 −12pp。对此有三种互斥的解释，本 plan 的五项实验就是设计来把它们分开的：

| 假说 | 内容 | 若为真，应看到 |
|---|---|---|
| **H-A（静态混叠）** | 单帧 key 把不同状态映射到相近位置，历史本可消歧，但算子没做到 | 高相似 pair 的动作分歧率显著 > 0 |
| **H-B（时间对齐脆性）** | 历史信息有用，但"第 t−1 帧对第 t−1 帧"的刚性对齐在轨迹快慢不一时失效 | 阶段对齐后历史应恢复增益 |
| **Markov 充分性** | teacher（Pi0.5）本身无记忆，`I(a*_t; h_t \| o_t) = 0` 由构造成立，cache 继承这一性质 | 历史在任何对齐下都无增量 |

三者的关键差别在于**信息是否存在**（条件 a）与**算子能否表达**（条件 b）。"历史有用"需要两者同时成立；任一不成立都会表现为"加历史反而更差"。

## 2. 离线证据（E1 / E1-O / E3 已完成）

### 2.1 H-A 被明确削弱

E3 在生产 key 空间里直接量了混叠：top 1% 相似的同任务跨-episode 对中，动作分歧率（超过正常时间演化的幅度）**spatial 0.24%、libero_10 2.79%**，而随机对是 47–48%。绝对臂（CI 上界 ≤ 5%）与相对臂（与随机对之差的 CI 上界 < 0）双双成立，两 suite 均判 `almost_no_aliasing`。

这个结论不依赖某一种 key 编码：**6 个 key builder × 2 suite 共 12 个组合全部同判**，spatial 落在 0.24–0.71%、libero_10 落在 2.03–2.38% 的窄带内。

⇒ **"单帧 key 把不同状态混在一起"在这批 artifact 上几乎不成立。** H-A 不是 d1 天花板的解释。

### 2.2 H-B 被明确削弱

E1-O 是本项目唯一真正的阶段对齐检验（`progress = cycle / (总 cycle − 1)` 的归一化进度，用到 rollout 时不可得的 episode 总长，故只能离线做）。预注册判据是"Δ% ≥ 5% 且 CI 下界 > 0"：

**8 个 (suite × ε × depth) cell 中，0 个支持 H-B。** 最关键的一条是 spatial 在 ε=0.05 下 Δ% 精确为 **0.00%** —— 未对齐时 B-d3 相对 A 的 +5.35% 增益，在严格进度对齐后**完全消失**。

这不是候选池退化的伪影：对齐后的候选池中位仍有 8（spatial）/ 20（libero_10）个，最小 3 个，**没有任何 query 退化到 ≤1 个候选**。

⇒ 未对齐时那点增益的来源，更像是**历史在替代性地补偿阶段错位**，而不是历史携带了 Markov 之外的信息。一旦阶段被真正对齐，历史就没有可加的东西了。

### 2.3 但严格版的 Markov 充分性也**不能**被宣称

E1 的四个 primary cell 里有三个在 Holm 后区间下界 > 0：spatial 的 B-d3 (+5.35%)、C-g1.0 (+8.80%)，libero_10 的 B-d3 (+2.86%)。也就是说，**历史/差分特征确实带来了可测的、小幅的残差降低**，即 `I(a*; h | k_t) > 0`。

> **修订 2026-08-14**｜本段原写作"`I(a*; h | k_t) = 0` 的强版本在 spatial 上被削弱"。该措辞不准确，容易被读作继承定律受损，故改写。
>
> 继承定律（纪要 §13 引理 1）的陈述是 **`I(a*; h | o_t) = 0`——条件在完整观测 `o_t` 上**，由 teacher 无记忆构造成立；本实验既未检验它、也无法检验（需完整 `o_t`）。E1 测的是**条件在有损 key `k_t` 上**的另一个量，而 §13 **引理 2** 明确给出 `I(a*; h | k_t) ≤ I(a*; o_t | k_t)`，即该项**允许为正**，上界是 key 丢失的观测信息量。
>
> ⇒ **E1 的结果不是对理论的削弱，而是落在引理 2 预测的去噪通道内。** `I(a*; h | k_t) = 0` 从来不是本项目的主张。

同时没有任何一个 cell 达成二元判决：libero_10 的 B-d3 未过 5% 效应地板，其余三个的 pilot power < 0.8（0.35–0.73），按预注册规则自动降级为估计性；TOST 在四个 cell 上均不成立，所以**也不能反过来声称"等价于零"**。

⇒ 诚实的表述是：**离线残差意义上历史有一点信息，但它在阶段对齐后消失，且在生产算子（`top_k=1` 的加权相似度检索）下取不到。**

### 2.4 表达力才是瓶颈的直接证据

exploratory 网格里有一条与算子直接相关的观察：**k=5 下的效应普遍远大于 k=1**——libero_10 的 C-g0.5 从 −0.20%（k=1）跳到 **+10.24%**（k=5），C-g1.0 从 −1.74% 跳到 +9.25%。

生产路径是 `top_k: 1`。所以这部分增益**在生产里根本取不到**。这与纪要 §5 的表达力闭包论证一致：`TrajScore = Σ_l w_l · s_l` 这种"逐帧标量化 + 非负可加"的结构等价于一个低通平滑核，它能做的是抑制噪声，不能表达 dynamics 通道。

### 2.5 E2 与 E3 的表面张力，及其正确读法

E2 在 libero_10 上看到：失败 episode 的 winner 更常来自"错阶段"。**无条件 estimand（`always_hit`，950 ep/suite）下高 +26.9pp**（CI [+21.5, +31.9]，判 `aliasing`）；条件性 estimand（threshold judge）下 +16.5pp。spatial 上 primary +6.9pp（CI [+4.2, +9.9]，排除 0 但未过 10pp 实用界）、secondary +2.05pp（CI 含 0），两者均判 `inconclusive`。

**两源的差距本身是结果**：threshold judge 的接受与"查询是否落在库覆盖良好的区域"直接相关，它系统性地滤掉了最容易出问题的步——把 libero_10 的效应从 +26.9pp 压到 +16.5pp。这也说明 secondary 的 `inconclusive` 不是"效应不存在"。

这与 E3 的"几乎没有混叠"**不矛盾**，因为两者问的不是同一个问题：

- E3 问：**key 空间里相似的东西，动作是否相似？** 答：是（分歧率 <3%）。
- E2 问：**失败时取回来的东西，时间位置是否更偏？** 答：libero_10 上是。

一个自洽的解释是：失败 episode 的查询**漂到了库覆盖稀疏的区域**，那里最近邻只能来自别的阶段——这既不需要"相似的东西动作不同"（E3 已排除），也不需要历史能救（E1-O 已排除）。E3 的 `|Δcycle|` 分层给这个解释提供了旁证：分歧几乎只出现在时间远的对上（libero_10：0–2 → 1.2%，>5 → 16.0%），说明**相似度本身已经隐含编码了阶段**。

⇒ **任何把 E2 读成"静态混叠导致失败"的写法都与 E3 直接冲突**，本报告不采纳该读法。

## 3. 一个未能执行的检验（诚实记录）

剂量-反应（key 质量谱系 × 历史增益）**没有被真正执行**：6 个 key builder 的质量代理 `median r_A` 跨度只有 spatial 7.5% / libero_10 2.6%，远小于 y 的变异，自变量本身没有信号。E3 独立地看到同一件事（6 个 builder 的 ADR 高度同质）。

⇒ 不得据此宣称"rescue-the-weak 的离线影子未被观察到"。要做这个检验需要刻意构造弱 key（降维 / 加噪的编码），本 plan 未采集。

## 4. E4 — 名义 inference-index 过滤消融（完成，8600 ep）

详见 [`e4_index_filter.md`](e4_index_filter.md)。

**primary `A3 − A1`：两个 suite 都未发现改善。**

| suite | 风险差 | Holm CI | π_d^obs vs proxy Q75 | verdict |
|---|---|---|---|---|
| libero_spatial | −2.21pp | [−5.16, +0.74] | **0.163 > 0.12 → 降级** | `estimation_only_discordance_above_proxy` |
| libero_10 | +0.21pp | [−2.74, +3.26] | 0.217 < 0.31 | `no_improvement_found_inconclusive` |

spatial 触发了 §3.5.4 的预注册降级规则（只依赖 nuisance 参数、不依赖效应方向，故非 outcome-dependent）。两个结局都是"未发现改善"，**不是等价** —— 等价需 CI 落入 ±3pp，两者都不满足。

**interaction `(A3−A1)−(A2−A0)` 的两个 CI 都含 0**（spatial +1.26pp [−1.16, +3.68]；libero_10 −1.05pp [−4.00, +1.79]）⇒ **加不加 index 过滤，depth 效应的大小没有可检出的变化；过滤不是 depth 失效的原因。**

**复现性检查 `A2 − A0`**：spatial **−3.47pp**（CI [−6.11, −0.84]，排除 0）复现了历史的 depth 退化；libero_10 +1.26pp（CI 含 0）未复现 —— 与该 suite depth 效应本就微弱、存在 d3-trough 松动信号一致（E5 正为此设计）。

### 4.1 一个 plan 未预见的机制：`step_filter` 制造 MISS

| 臂 | spatial SR / MISS | libero_10 SR / MISS |
|---|---|---|
| A0（d1 + all） | 0.6642 / **0%** | 0.4516 / **0%** |
| A1（d1 + window） | 0.7126 / 20.2% | 0.5253 / 25.7% |
| A2（d3 + all） | 0.6295 / **0%** | 0.4642 / **0%** |
| A3（d3 + window） | 0.6905 / 19.6% | 0.5274 / 24.9% |
| A4（d3 + exact） | 0.7300 / **23.9%** | 0.4760 / **29.1%** |

plan §5.2 假设"`always_hit` 下每步都有 winner"，**这在加了 `step_filter` 后不成立**：MISS 不是 judge 拒绝，而是 index 过滤把候选集清空，那些步回退到 teacher 推理（teacher anchor SR 0.83 高于任何 cache 臂）。

⇒ `A1 − A0`（+4.8/+7.4pp，CI 均排除 0）**不能**读作"过滤提高了检索质量"，它是"过滤 + 20–26% 的步改用 teacher"的联合效应。A4 在 spatial 上 SR 最高（+11.4pp vs A2）**同时** MISS 率最高（23.9%），是同一机制最直接的体现 —— 它测的与其说是 exact 对齐的价值，不如说是"更频繁地放弃 cache"的价值。要分离两者需要一个"同比例随机弃用 cache"的对照臂，本 plan 未采集。

**对主线论证的意义**：primary 与 interaction 双双落空，说明**在生产可配置的时间维度旋钮里，没有一个能让历史变得有用**。这与 E1-O（真正的阶段对齐下增益归零）指向同一结论，只是 E4 走的是 rollout 而非离线残差。

## 5. E5 — libero_10 d3-trough 确认性重跑（完成，3800 ep）

详见 [`e5_d3_confirmatory.md`](e5_d3_confirmatory.md)。

**原 d3-trough 信号没有复现。** 四臂全部在原信号所在的 `0.62/0.37/0.00` base 上，d1 anchor 由同一 d3 yaml 派生（不复用历史 anchor）：

| 臂 | 原筛选身份 | SR | 风险差 vs anchor | 95% CI | verdict |
|---|---|---|---|---|---|
| d1_anchor | — | 0.4747 | — | — | — |
| shape0 [0.2,0.1,0.7] | rank 1, trough, 原 +6.0pp | 0.4737 | **−0.11pp** | [−3.37, +3.16] | **`not_supported`** |
| shape1 [0.2,0.3,0.5] | rank 2, increasing, 原 +6.0pp | 0.4737 | **−0.11pp** | [−3.37, +3.16] | **`not_supported`** |
| shape2 [0.5,0.2,0.3] | rank 3, trough, 原唯一 CI 排除 0 | 0.4989 | +2.42pp | [−0.74, +5.58] | `inconclusive` |

从 171 个配置中挑出的 top-3（各 +6.0pp），在独立重跑中落到 −0.1 ~ +2.4pp —— **一个干净的 winner's curse 案例**。判读用预注册的四分规则，全程未使用 p 值。

`not_supported` 的准确含义是"原报告的 4pp 效应量不被支持"，**不是**"效应为零"：区间仍容纳 ±3pp 的真效应，而 950 ep 是 held-out 上限，判定 4pp 需 1347–1518 ep，这是**预先声明**的精度限制。

次要分析（不进比较族）：三个形状在 E3 标出的高-ADR 任务子集（n=285）上都优于全集，shape2 达 +5.96pp。方向与"静态混叠消解"通道一致，但事后切分、无多重性校正，只能作提示。

**对主线的意义**：若 d3-trough 是真信号，就意味着某个特定轨迹权重形状能提取历史信息——那将与 E1-O（阶段对齐后归零）和 E4（两个时间旋钮均无改善）冲突。它没有复现，因此不构成反例。

## 7. 全局 caveat

- **库的 `outcome` 全为 `None`**：所有"取回物来自成功还是失败轨迹"的条件分析在本数据上都做不了。
- **离线残差 ≠ SR**：E1/E3 是离线量，与闭环成功率之间没有本实验能建立的因果链。
- **E2 是观察性的**：错阶段 winner 与失败共现，不等于前者导致后者；反向解释同样成立。
- **样本量是硬上限**：950 ep/臂 已用尽 db_init + 官方 pruned 两池的全部 held-out 容量，不存在扩样空间；因此多处判决预先降级为估计性，而不是事后论证功效。
- **本实验不检验 teacher 是否真的无记忆**，只检验 cache 检索这一层是否需要历史。
