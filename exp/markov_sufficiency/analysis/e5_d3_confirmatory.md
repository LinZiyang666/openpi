# E5 — libero_10 d3-trough 的确认性重跑

> 3800 个配对 episode（4 臂 × 950），全部在 **`0.62/0.37/0.00`** base 上
> 判决层级：**估计性**（目标 4pp 需 1347–1518 ep，超过 950 的 held-out 上限）——**不做 p 值判决**
> 产物：`data/e5/e5_result.json`、`data/e5/arms_libero_10/`

---

## 1. 一句话结论

**原筛选中的 d3-trough 信号没有复现。** 171 配置筛选里 rank 1/2 的两个形状（原报告各 +6.0pp）在同 base、同批次 anchor、950 ep 的确认性重跑中降到 **−0.11pp**，CI 上界 +3.16pp < +4pp ⇒ 按预注册规则判 **`not_supported`**，winner's curse 的读法得到支持。rank 3 的形状 +2.42pp，CI 含 0 且上界越过 4pp ⇒ `inconclusive`。

---

## 2. 设计的命门：base 必须对

原 d3-trough 信号产生在 **`cp1_spatial_pool_16__grid_vision_0@62_vision_1@37`**，即模态权重 **vision_0=0.62 / vision_1=0.37 / robot_state=0.00**。plan 原稿曾指定另一个 base（`grid3_…@56_25_18` = 0.5625/0.25/0.1875），在它上面重跑会**同时改变模态权重与轨迹形状两个变量**，得到的既不能确认也不能否证原 winner。

本实验的四个臂因此全部在 `0.62/0.37/0.00` 上，且 **d1 anchor 由同一个 d3 yaml 派生**（删 `trajectory_weights`、`trajectory_depth: 1`，其余字节不变），**不复用历史 anchor**——历史 anchor 可能含批次漂移，而确认性重跑的全部意义就在于消除这类差异。

| 臂 | trajectory_weights | 原筛选中的身份 |
|---|---|---|
| `d1_anchor` | —（depth 1） | 同 base 的 d1 参照 |
| `shape0` | [0.2, 0.1, 0.7] | rank 1，`s2_2-1-7`，trough，原 +6.0pp |
| `shape1` | [0.2, 0.3, 0.5] | rank 2，`s2_2-3-5`，increasing，原 +6.0pp |
| `shape2` | [0.5, 0.2, 0.3] | rank 3，`s2_5-2-3`，trough，**原筛选中唯一 bootstrap CI 排除 0 的** |

---

## 3. 结果

| 臂 | SR | 配对风险差 vs anchor | 95% bootstrap CI | verdict |
|---|---|---|---|---|
| `d1_anchor` | 0.4747 (451/950) | — | — | — |
| `shape0`（rank 1） | 0.4737 (450/950) | **−0.11pp** | [−3.37, +3.16] | **`not_supported`** |
| `shape1`（rank 2） | 0.4737 (450/950) | **−0.11pp** | [−3.37, +3.16] | **`not_supported`** |
| `shape2`（rank 3） | 0.4989 (474/950) | **+2.42pp** | [−0.74, +5.58] | `inconclusive` |

预注册的四分判据（plan §5.5）：CI 上界 < +4pp ⇒ 原信号不被支持；CI 下界 > 0 ⇒ 复现；两者皆非 ⇒ 证据不足。**没有使用 p 值**。

原筛选中 top-3 的 +6.0pp，在确认性重跑中全部落到 −0.1 ~ +2.4pp 区间。**这是一个干净的 winner's curse 案例**：从 171 个配置里挑出的最大值，其效应量在独立重跑中系统性缩水。

### 3.1 shape0 与 shape1 的统计量逐位相同 —— 不是 bug

两臂的风险差与 CI 完全相同，值得解释：

| 臂 | 成功数 | b（该臂成功、anchor 失败） | c（anchor 成功、该臂失败） | b−c | π_d |
|---|---|---|---|---|---|
| shape0 | 450 | 127 | 128 | −1 | 0.2684 |
| shape1 | 450 | 127 | 128 | −1 | 0.2684 |
| shape2 | 474 | 129 | 106 | +23 | 0.2474 |

两臂**不是同一次 rollout**：逐 episode 比对有 **128 个结局不同**。但配对二值差只取 {−1, 0, +1}，其经验分布**完全由 (b, c, n) 决定**——(b, c) 相同则 bootstrap 分布相同，区间必然逐位相同。这是配对二值数据的性质，不是重复计算。

## 4. 次要分析：高-ADR 任务子集（不进主比较族）

E3 给出 libero_10 的 per-task ADR 排序；取达到报告门槛的高-ADR 任务，在其子集上重算风险差：

| 臂 | 全集（n=950） | 高-ADR 子集（n=285） |
|---|---|---|
| shape0 | −0.11pp | +2.11pp |
| shape1 | −0.11pp | +1.40pp |
| shape2 | +2.42pp | **+5.96pp** |

三个臂在高-ADR 子集上都比全集更好，shape2 尤其明显。**这是趋势提示，不是结论**：子集是事后按 E3 的 ADR 排序切出来的，n=285，没有多重性校正，也不进任何比较族。若"静态混叠消解"通道真实存在，效应应集中在混叠更严重的任务上——本数据与该预测方向一致，但不足以支持它。

## 5. Discussion — 本实验**不**能证明什么

- **不能证明 d3-trough 效应为零。** `not_supported` 的判据是"CI 上界 < 目标 4pp"，即**原报告的效应量不被支持**；shape0/shape1 的区间 [−3.37, +3.16] 仍容纳 ±3pp 的真效应。样本量 950 是 held-out 上限，判定 4pp 需要 1347–1518 ep，本实验先验地不具备该精度——这是**预先声明**的降级，不是事后辩解。
- **shape2 的 +2.42pp 没有被否定。** 它的 CI 上界 +5.58pp 越过了 4pp，所以"证据不足"，既不能说复现也不能说否证。它恰是原筛选中唯一 bootstrap CI 排除 0 的配置，值得在更大样本上重看。
- **不能推广到别的 base。** 全部四臂在 `0.62/0.37/0.00` 上，这是为了让"确认"有意义而付出的代价：结论只对该 base 成立。
- **高-ADR 子集不是证据。** 见 §4。
- **配对只锚定 init、不锚定 noise**（与 E4 同口径），flow-matching 采样噪声每次独立，稀释配对效率但不引入偏倚。π_d ≈ 0.25–0.27 的实测不一致率正反映了这一点。

## 6. 与其他实验的关系

E5 是唯一一个"针对具体历史信号做确认"的实验，其余四项测的是机制。它的 `not_supported` 与 E1/E1-O/E3/E4 的结论**同向**：

- 若 d3-trough 是真信号，就意味着某个特定的轨迹权重形状能提取历史信息 —— 那会与 E1-O（阶段对齐后增益归零）和 E4（两个时间旋钮都无改善）冲突；
- 实测它没有复现，因此不构成对主线结论的反例。

合并解读见 [`synthesis.md`](synthesis.md)。
