# R17 全组 SR / IR 重算（最终数据链，2026-10-22）

## 口径

- **数据**：每组只读最终数据链的末段，`analyze_cache.resume_segments` 沿 CACHE_RESUME 往回走，只收 accepted、丢 retry-exhausted 行，同一局取 ts 最晚的那条。改名、pod `_j` 副本按 completeness_audit 的最终链（覆盖表 `longseg_1017/FINAL_CHAINS_1022.json`），CAMPAIGNS.json 未改。
- **选档**：现行分析代码原样。旋钮关整格（500/2,500 局）成功数不低于同步数纯推理的，直接用旋钮关、不调；否则逐任务从高档往下，首次比纯推理少 3 局及以上就冻结上一档（2 局容差）。MetaWorld 逐任务降到 pure 时，用纯推理+长执行段的新局（不拿原长度纯推理局顶替）。
- **SR**：MetaWorld 先列四难度组（easy 28 / medium 11 / hard 6 / very hard 5）等权均值，再列逐任务均值；LIBERO 列 500 局成功率。「纯推理 SR」是同步数、原执行长度的纯推理参照（选档的目标）。
- **level IR**：R17 = 模型调用的段头 / 全部段头（尾段两边都不计）；π0.5/GR00T = R15/R16 账本里的模型调用 / 有视觉的决策（尾段不计）。
- **正式 IR**：R17 和 Cosmos = 4090 计时档案（batch 1、compile CUDA graph、独占）按 `IR = (v·(调用+命中) + m·调用)·C0 / 控制步数` 计价，以全步纯推理一次决策为 1；括号里是同步数纯推理的正式 IR。π0.5/GR00T = R15/R16 原生每决策成本账本（D5 计价，`rounds/r16/cost.py`），现有代码对这两个模型只有这一种 IR。
- **局数**：最终用于该格 SR 的局数（MetaWorld 2,500，LIBERO 500）。「读取」列的编号见文末批次表。
