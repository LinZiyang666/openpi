# R10 报告：示范库大小 × 库内训练修正器 消融

协调者撰写，2026-10-02。owner 目标（/goal）：
- 补一个缓存（示范库）大小消融：50 / 100 / 200 / 300 / 400 / 500 集，小库从 500 集库里切出来；
- 修正器只用示范库本身训练（库里每一行都是大模型推理的输出），比较"留本集检索"和"与距离内的点配对"两种训练法，判断哪个好。

## 数据纪律（与 R9 的区别）
- **评测**：LIBERO 官方测试集（每任务官方 50 个起始状态，共 500 局）。每个配置只测一次，测试集不参与任何拟合、标定、阈值或挑选。
- **拟合**：一切都只用差集池建的示范库（π0.5 用 `bpool_cs`，GR00T 用 `bpool_all`），以及由它切出的嵌套子集。缓存度量、守卫阈值、修正器头都在库内拟合，代码里有路径守卫，拒绝读任何闭环运行目录。
- **不用掉队接手**：它的阈值在 R9 里是用测试集拟合的。
- **子库**：每任务把 50 集用固定种子打乱，取前 5 / 10 / 20 / 30 / 40 / 50 集，所以小库嵌在大库里。原库里的失败示范照样保留。
- **磁盘**：h100 不复制任何子库数组，拟合产物按行号引用 500 集父库。

## 每个库大小 5 组
- **A**：纯缓存。
- **G**：只留"无进展"守卫。
- **GC_loeo**：G + 留本集修正器（每行用"排除本集"的部署检索合成缓存动作，学"大模型动作 − 缓存动作"）。
- **GC_pair**：G + 配对修正器（每行与距离在中位数内的他集行配对，每行最多 16 对，权重按锚点归一）。
- **GC_dist**：G + 留本集修正器，但强度随离库距离减弱：离库近时一半，到标定距离 2 倍时为 0。astra 设计，冻结前没有看任何闭环结果。

修正器的头、正则、强度 .5 等都与 R9 相同，只有训练数据不同。

## 给 owner 的结论（白话）

**一、库大小**
- **长任务**：纯缓存随库变大一路上升，π0.5 从 .634 到 .836，GR00T 从 .608 到 .810。守卫在每个大小都再加 4–18 个点（6 档合并配对 p<1e-20）。
- **短任务**：100 集就饱和了（纯缓存 .95–.98），守卫只在 50 集上有用。
- **示范质量**：随机抽的 50 集远不如部署用的精选 50 集。π0.5 长任务 .634 对 .718，GR00T 短任务 .794 对 .868。小库里示范质量不亚于数量。

**二、修正器有用，而且这次是干净的**（只用示范库训练）
- **留本集修正器**：
  - π0.5 长任务 6 档合并，比只留守卫多成功 266、少成功 185，p≈.0001；
  - GR00T 长任务多 355、少 257，p≈.0001；
  - π0.5 短任务多 87、少 53，p≈.005；
  - GR00T 短任务持平，500 集库上反而 −3 个点。
- **开销**：加修正器后推理开销还略降约 .01，因为缓存卡住得少了，守卫叫大模型也少了。
- **长任务大库已追平纯推理**：π0.5 .900–.914，纯推理 .908；GR00T .902，纯推理 .898。

**三、两种训练法：留本集更好**
- **配对法**：π0.5 上有用，与留本集持平；GR00T 长任务上完全无效（多 315、少 316），比留本集差（多 347、少 248，p≈5e-5）。原因是训练时它看到的是单个邻居的动作，部署时却是 16 个邻居的加权平均，输入对不上（opus 离线分析的结论，闭环得到验证）。
- **按距离调强度版（GC_dist）**：长任务上与固定强度留本集持平；GR00T 短任务上更稳，比只留守卫多 136、少 98，p≈.01；比固定强度留本集多 110、少 77，p≈.02。避免了固定强度在 GR00T 大库短任务上的轻微伤害。

**四、建议**
1. 把"库内留本集训练"的修正器并入设计，替换 R9 那个在测试集上训练的修正器。
2. 两个版本之间推荐**按距离调强度版**：长任务一样好，短任务更稳，规则只用示范库标定。
3. 仍需你裁定的问题：修正器还是**每个任务一个回归头**，即按任务编号选头。

- **比只留守卫**：GR00T 两格显著更好（+6 / +4 个点）；π0.5 两格差异不显著（−2 / +2 个点）。
- **精选库与随机库**：两者纯缓存差距很大，但加上守卫和修正器之后，三层设计在两种 50 集库上成功率接近，差 −1.6 到 +2.6 个点。
- **注意批次**：对照是 R8 的跨批次结果。同配置重跑约有 10% 的局结果不同，跨批次差 2–3 个点以内不宜解读。
- **与 R9 的比较**：R9 "最终配方"在同一精选库上的 .894 / .832 用了测试集拟合的修正器与掉队阈值，不可比。
