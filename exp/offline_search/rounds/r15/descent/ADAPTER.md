# R15 adapter scope

`PROTOCOL.md` is byte-identical to the frozen R14 protocol. D1 changes only the 12-cell design and arm layout: five descent arms in each cell, with one same-init C10 reference per model/suite. Each library size is a four-cell group; the original 200-comparison dev band and 40-comparison test band apply separately to each group. No jointly simultaneous 600-comparison claim is made.

`analyze.py` and `analyze_test_a.py` are copies of R14's scripts with layout/identity/report adapters. `paired`, `cell_pair`, `descend`, `stitch`, `bootstrap_indices`, `savings`, accepted journal semantics and cost reconciliation retain the original equations. B identities are now indexed by model/suite; shared dev C10 is loaded from its own root. Size 100/200 must be disjoint from their actual served subsets. Size 500 must have the attested opt-in contract and real-look audit excluding its own episode from both candidate and donor lists. Every read input is hashed and checked again before writes. Missing, malformed or unpaired data abort.

The R14 `task_periodic` allocation comparison arms are explicitly not repeated by D1. Their library agreement and matched-allocation diagnostics are therefore unavailable, rather than invented. The complete unchanged numerical functions remain in the copy for provenance; the adapter does not call those unavailable comparisons.

Test A stays measure-only: it reads the frozen B provenance/tables, the two new arms per cell, and R14's same-model/suite pure C10 reference. C10 identity/template/fit/config hashes are bound in `c10_proof.json`. New-arm completion timestamps must follow B selection; the reused older reference is exempt from that chronology check. Pooling and bootstrap comparisons run separately for sizes 100/200/500, never pooling the same C10 reference three times. The default CLI verifies the protocol and reads no outcomes; only explicit `apply` opens B or A run outputs.

Size-500 B serving excludes its own episode from retrieval, auxiliary visual/state/distance searches, corrector donor distances, guard donor features and optional exact action matching. All fitted parameters still include the excluded episode; this mild optimistic fit bias is disclosed. The test-A emitter uses ordinary, unfiltered size-500 artifacts: A and B numeric init indices name distinct physical states.

`levels.example.json`, `uniform.example.json` and `emitter_smoke/` contain arbitrary CPU examples, never selected experiment results. No A roots are installed or launched here.

`analyze apply --models pi05` (or `groot`) now requires only that model's complete registered cells and shared B C10 references. Selection and all cell statistics are computed by a cell-local function, independent of other cells. Partial outputs use model suffixes, including provenance and tolerance alternates. The unchanged 200-comparison bands are reported as partial within each size group; cross-cell pooling is deferred. A later full apply compares the serialized primary and alternate tables against existing partial files byte-for-byte before writing; repeated partial apply also preserves its frozen tables. The existing emitter, verifier, planner and installer accept these six-cell subsets, with separate staging directories and the existing `@h100` / `@local` host routing.

The frozen protocol and its original source hashes are not rewritten. `partial_apply_adapter.json` records the authorized analyzer source update, its original frozen source digest, its current digest and the original numerical/loader AST digests. Fifteen numerical and accepted-row functions remain AST-identical; the separately authorized H100 served-fit loader fix is bound to its pre-fix source and current loader AST (see `LOADER_FIXES.md`). `partial_apply_original_analyze.py.txt` preserves the exact original source. The coordinator log already had a later D5 track-B append: `partial_apply_original_coordinator_decisions.md` preserves the SHA-matching 1,849-byte frozen D1-D4 prefix, which verification still requires byte-for-byte. Later appended notes are provenance only and cannot enter selection. All other frozen inputs still require their original hashes.
