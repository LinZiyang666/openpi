# R15-B gates, frozen before any new-method closed-loop outcome

These gates are set after the documented offline exploration, before any new-method online outcome. They are development decisions, not retroactive claims that the exploratory results were a preregistered test. The final SHA256 manifest freezes this document with SPEC/PREDICTION/REQUESTS.

**Current disposition: do not run online.** No explored L10 candidate has cleared the unseen B-dev accuracy requirement. Per `OWNER_ADDENDUM.md`, a closed-loop pilot requires both an offline pass and coordinator approval. An attractive latency or library-LOEO number cannot waive the B-dev requirement.

## Offline gates, in order

1. **Data and implementation.** Train only on the exact cell library, including every normalizer and fit; zero own-episode donors in library LOEO; zero train/init overlap in the chosen B-dev set; no test A or external weights. All image/state/action alignments and representation identities pass. Teacher-reference replay must reproduce ≥99.9% of top-16 sets on a matching recorded cell (the current size-50 checks reproduce 100%). All returned chunks finite. Fail closed on missing labels or unknown image provenance.
2. **Library pseudoqueries first.** Every library row, same-task donors, complete own episode excluded. Final learned representation is fixed, matching deployed confidence calibration; report its training dependence. Equal-episode/equal-task RMS10 must be ≤1.05× the deployed-key reference, no task >1.15×. Report RMS5, action-tail RMS10 p90, top-1/top-16 agreement and known library-phase error. A pass here is necessary, not sufficient.
3. **Existing unseen B-dev.** All-look shadow-policy labels, including failed episodes; accepted-attempt deduplication. Equal-episode/equal-task RMS10 ≤1.05× reference and paired episode-bootstrap 95% upper excess ≤.10; no task's RMS10 >1.15× reference. Top-16 mean overlap ≥.75; top-1 agreement is reported but has no standalone veto. Phase backwards jumps >.10 normalized donor progress may exceed reference by at most .02 absolute; teacher-phase discrepancy >1/3 may occur on at most .05 of looks. These are phase proxies, not true B-dev phase labels. Report both equal-task and look-weighted estimates. Do not count cache HIT outputs as policy labels. MISS-only Spatial data cannot pass this gate. L10-50 and L10-200 must each pass; do not pool away a failing cell.
4. **Per-look cost.** Batch one, both cameras, raw RGB to usable CPU retrieval code, including resize/conversion/transfers. Primary ε ≤ c_v/10 at the deployment host/stack; p95 ≤ c_v/5. Measure at least 400 timed looks after warmup and publish quartiles/p95. CPU is preferred. Report the historical owner π0.5 CUDA-graph basis (10.26-ms stage 1, .152 coefficient) as a conservative sensitivity: its median budget is **1.026 ms**. Also report same-production-stack normalization separately. Do not pass a GPU/host condition using another host's measurement. No GPU use unless CPU is infeasible and the reason is recorded; historical GPU measurements may be reused without new GPU work.
5. **Complete offline artifact check.** Refit layers 1–3 on the same library; verify real plugin decisions with tower functions instrumented to raise on light HITs. Check teacher-path identity when light mode is off, single commit, full-policy MISS, blind continuation, parent rows and ledger arithmetic. The current key-only prototype does not satisfy this deployment gate.

Bootstrap: 2,000 stratified paired episode draws, seed 20261005, ten tasks kept equally weighted. Intervals describe this reused B-dev sample and omit hyperparameter selection uncertainty. LOEO uses no B-dev training. If a method changes after seeing any later closed-loop outcome, version the method and gates before a new comparison; do not silently move thresholds.

## Planned B-dev closed-loop checks — not authorization to run

The SPEC pilot has one student and matched baseline at off and fixed-cap ir25, 100 paired episodes each. Both settings must have cell SR delta ≥−2 percentage points; no task may lose more than one net success out of ten at this coarse pilot stage. Report paired gains/losses and uncertainty, all execution errors and retries. Any cell/setting failing stops promotion; do not compensate a regression with another task, knob or library size. An initial smoke, if the coordinator performs one after approval, establishes implementation only and cannot count as an SR pass.

For passing cells, extend to 300 paired episodes/arm (30/task). Required: cell SR delta ≥−2 pp; every task delta ≥−5 pp (at 30 episodes this permits at most one net loss); conservative paired one-sided 95% lower bound on the cell delta ≥−5 pp. Use `CP_low(g,n,.025) − CP_high(l,n,.025)` for the cell and report task intervals. This is a development noninferiority screen at the stated tolerance, not proof of exact equal SR. Missing/error episodes are resolved under collector semantics; no success-conditioned deletion.

**Large total savings**, measured with actual new counts and the new ledger: off must reduce IR by ≥25% relative; ir25 by ≥15%; the frozen π0.5 L10 R14 task table by ≥15% in a separately labeled fixed-table comparison/projection. Report achieved IR, N/V/M, absolute savings, total cost per episode and executed controls; premature failure must not masquerade as useful savings. High-inference ir40/ir45 and the GR00T L10 R14 table have small theoretical savings and are not the economic target. Never demand a large saving where even ε=0 makes it impossible.

No test-A read, tuning or run is part of these gates. A later test-A confirmation, if requested by the owner, requires frozen model/knob/table and a separate coordinator action. Size 500 has no unseen B init and cannot borrow the 50/200 unseen-validation label.
