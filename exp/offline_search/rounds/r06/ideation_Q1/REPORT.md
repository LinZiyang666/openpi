**Q1 result: useful library diagnostics, but no validated universal success score.**

The owner’s leave-one-episode-out idea detects improvements within a fixed model/suite and exposes where a bank lacks support. It does **not** establish an absolute quality scale that ranks closed-loop A across models/suites. The delivered composite is an interpretable reconstruction/support score, with a global summary, task summaries, and an online anchor implementation. It is **not a success probability, a policy-call utility, or an automatic MISS threshold**. A small independent trajectory sample calibrates its predicted errors, but does not repair its weak pooled SR ranking.

All computations are offline, on CPUs 10–13,54–57, with single-thread BLAS and CUDA disabled. No simulator, server, chain, tmux session, port, remote host, git operation, or shared data mutation was used. The closed-loop data are existing completed results; `r06_paper` was not incorporated while it was running.

**3. Exact portable algorithm and calibration recipe**

Deliver **(support, action reconstruction, successor reconstruction, Q)** as a diagnostic vector. Report Q globally and per task; expose online Q and its components at an anchor. Keep the components because a single scalar is demonstrably inadequate across the four cells. `quality.py` implements `Calibration.at_anchor(task, rows, weights, nearest_distance)` without camera counts, robot coordinates, gripper signs, benchmark names, policy calls or simulator access. `load_audit_calibration` is just the adapter to the delivered data.

1. **Declare the deployment contract from metadata.** Supply the deployed embedding/metric/kernel, task or instruction grouping, valid action/state coordinates, executed recording interval Δ, and cached commitment H. In this experiment Δ=5, H=10, two PCA-64 views plus 8 state coordinates; those are properties of A and the recorded robot interface, not constants embedded in the portable score. Use the same trained retrieval transform and kernel as the controller. Do not apply recorded inference’s fresh-continuity reranking to pure-cache A. Missing task support means unsupported, not cross-task nearest-neighbor substitution.

2. **Define normalization from the candidate library alone.** Action scale σa,d is population std over the library’s first Δ valid action controls. State scale σs,t,d is population std of valid state coordinates among task t’s library rows. Score only physically valid, nonconstant coordinates supplied by the robot metadata; if a coordinate is constant in the library but changes in a query, flag unsupported variation separately instead of inventing a physical-unit floor. The measured adapter uses a 1e-12 numerical guard (fallback divisor 1); none of the measured valid action or state scales needed that fallback. The deployed retrieval fit itself retains its historical current-library action units; only quality-error normalization uses the candidate bank’s own units. This distinction is recorded explicitly rather than silently refitting the deployed retriever.

3. **Library leave-one-episode-out.** For every library row i, retrieve only same-task rows in episodes other than episode(i), in the frozen deployed geometry. For step zero use its deployed early metric; otherwise use its main metric. This is *conditional LOEO*, not an independent generalization guarantee. Select the deployed k=16 rows and weights `w ∝ exp(-((d-d1)/max(d[kref]-d1,1e-6))²)`, with actual one-based kref=5 or 8; normalize weights to sum to one. The portable implementation accepts weights from the retriever, so it does not impose this kernel on another robot/controller.

4. **Residual labels.** Let â be the weighted stored chunk. Action error `ea = sqrt(mean(((â[:H]-a_recorded[:H])/σa)²))`. Also retain head-only error over Δ and a second H-control diagnostic that stitches the next actually executed head onto the current head. The latter has a different meaning from the recorded policy’s proposed tail; omit it if no next head exists. For successor error at lag h=H/Δ (here two consecutive decisions), predict `δhat = Σ wj (sj+h-sj)/σs`. Omit candidate rows lacking that observed successor, renormalize their remaining weights, and record retained edge mass. Compare to `(si+h-si)/σs` with RMS over valid state coordinates. Omit query rows without that successor, and never invent a zero-motion terminal. Record one-interval successor error as an alternative. These are observed displacement predictors, **not counterfactual dynamics under â**.

5. **Distance calibration.** Per task, take at most 512 deterministic evenly spaced candidate rows (indices `unique(linspace(0,n−1,min(512,n),dtype=int))`). Let `st` be the median Euclidean distance between sampled main-metric codes from different episodes. Define `D=d1/st`. This reference preserves a bank’s density relative to its overall feature extent better than dividing by its own nearest-neighbor median. If fewer than two episodes or st=0, return unsupported. Also report `d1/median(LOEO d1)` as a distribution-shift diagnostic and `C95 = 1[d1 ≤ quantile(LOEO d1,0.95)]`, using NumPy linear quantiles over task rows. The early branch shares this main-geometry reference in the measured baseline; a separately calibrated early regime is an untested extension. C95 and the upper-tail rank `(1 + #LOEO distances ≥ d1)/(1 + nLOEO)` are internal diagnostics, not conformal coverage guarantees: the fitted transform reused the calibration episodes and states within an episode are dependent.

6. **Portable offline score.** On rows with valid successor labels, define `Q = 1/(1 + D + ea + es)`. All three coefficients are exactly 1; no closed-loop outcome fitted them. Its range is (0,1], and **1 means zero measured discrepancy, not certain task success**. Compute row means within an episode, episode means within each task, then equal-task means globally. Export the components alongside Q. Report fixed recorded-inference and recorded-cache query scores separately; do not mix their different state distributions. Five progress bins, first C95 break, and longest uncovered-run/episode-length are reporting diagnostics only. No future progress or success flag enters online Q.

7. **Online anchor version.** For an actual retrieval, retain its rows, normalized weights and nearest distance. Predict `eahat=Σwj ea_LOEO[j]` and `eshat=Σwj es_LOEO[j]`; unavailable successor residual labels use the task’s mean valid residual, with imputed weight exposed as `successor_evidence_mass`. Compute `Qanchor = 1/(1 + D + eahat + eshat)`. A missing entire task’s successor calibration gives no composite score. This uses only the current retrieval plus library calibration arrays. It requires no new observation beyond the anchor and no future outcome. Q alone adds two residual scalars per library row and task summaries; the full diagnostic adapter also retains one distance scalar per row plus task/episode identifiers; search cost itself is unchanged and online latency was not benchmarked here.

8. **Optional independent error calibration.** Before evaluating outcomes, reserve a deterministic 10% of recorded inference episodes within each task; use ordered episode identities, and choose at least one episode per task if possible. The actual 500-episode streams use the first 5 of 50 inits/task, with the explicit growth split above. Compute each component’s ratio `factor = (task-macro observed mean residual)/(task-macro predicted mean residual)` on calibration episodes. If the denominator is zero but observed error is positive, mark calibration unsupported. Multiply eahat/eshat by these factors; keep all other constants fixed. The remaining episodes are the error-calibration test, not training data. This is a mean-error calibration recipe, not a distribution-free bound or a probability-of-success calibration. Set `action_factor` and `successor_factor` on `Calibration` to use it. Fifty recorded episodes is the measured sample size here, not a requirement that transfers to every benchmark; a smaller sample must have its uncertainty measured rather than assuming these results persist.

9. **What can be deployed from this evidence.** Use Q and its components to audit bank growth, identify poorly supported tasks/states, and nominate a short list of libraries for paired evaluation. Do not choose a universal Q threshold for suppressing inference or claiming an SR target. For small libraries, prefer independently recorded probes for calibration and report the metric-refit LOEO sensitivity. A fully inductive episode split would refit PCA, metric and normalizers excluding the episode; that is a different quantity from coverage of the deployed fixed fit, and the full-PCA version was not computed here. No closed-loop labels are needed to compute this diagnostic; a separate SR calibration would require labeled closed-loop validation under the target controller, which the present correlations do not justify replacing.

**5. Risks and falsification**

- **Identifiability:** fixed recorded trajectories do not reveal the counterfactual states reached by a different action/controller. Two environments can agree on every observed transition and differ after an off-support action. Thus no universal SR guarantee follows from these inputs alone.
- **Representation leakage:** even after removing an episode from candidates, the deployed metric learned from it. The 14.7–18.1% metric-refit action-error increases quantify this risk at current size; no full-PCA inductive claim is made.
- **Covariate and source shifts:** current vs B-pool, successful-only growth, inference vs historical cache, early vs main metric, and different commitment lengths all change the estimand. Coverage’s internal threshold demonstrably fails as an absolute success threshold.
- **Loss mismatch:** standardized action imitation and proprioceptive successor error need not measure object/contact/task outcome error. There is no special gripper rule in Q; this improves portability but does not make contact consequences observable. Multimodal successful actions can also have high RMS discrepancy.
- **Uncertainty:** nested banks and repeated controllers are dependent; only four model/suite cells and two physical task suites exist. Task-cluster intervals do not integrate refitting or run-seed uncertainty. The small calibration sample improved error calibration in these stored streams, not out-of-robot success calibration.
- **What would falsify even the limited recommendation:** prospectively worse same-setting SR for reliably higher Q across the fixed-count pairs; near-zero/negative within-task error rank on new robots; error correction factors failing on independently held episodes; or size/source controls eliminating the apparent within-cell ranking. Each blocks using Q to select a library without paired SR tests.
- **What has already been falsified here:** interpreting C95 as an SR probability, assigning a universal Q→SR mapping across the four cells, and claiming lower conditional LOEO error alone solves controller selection. The existing R5 B1 six-cell negative test remains in force; this report does not overwrite it with retrospective correlations.

**6. Data we want but do not have**

Owner follow-up: requirements for the single superset profiler, **not a profiler implementation or a new experiment launch**. Priority is Q1: predicting A’s library-dependent SR, its gap to inference, and B’s gain, globally/per task/per state. The planned shadow chunk, randomized MISS, retrieval/guard internals, snapshots and outcome joins are accepted as the baseline. These collection targets do not replace §4’s eight-arm test plan.

The most important distinction is between **a second proposed action**, **a second observed transition**, and **a second complete-policy outcome**. The shadow chunk supplies the first. Randomized execution supplies factual transitions for both treatments over a population. A valid saved state plus later branch execution can supply paired transitions/outcomes from the same state. None of these by itself supplies pure-A SR on states reached under a different, repeatedly randomized controller.

Existing-data qualification: this is not a claim that all low-level fields are absent everywhere. `harness/store.py:QueryCell.ARRAYS` already defines keys, state and executed chunks for old recordings; `closed_loop/plugin.py:_write_inputs` can optionally save them, including blind-execution information. The sampled R5 A decision/client/journal schemas are preserved in `data_wishlist_existing_fields.json`; that run has decision records and a served head, but no complete every-anchor shadow/alternative-successor bundle. The existing K5 randomization is restricted to guard landmarks, π0.5 l10, and its old controller (`../../r05/q3_callvalue/HANDBACK.md`). The missing product is a complete, consistently joined dataset under the target A/committed-MISS execution, plus the counterfactual and independent-validation quantities below. Preserve an already-recorded field; do not duplicate it merely because it appears in this list.

**Precision conventions for every ranked item.** All requested sample sizes below are **planning targets/assumptions, not measurements of a new run or guarantees of power**. A base cell means model × suite; a bank cell additionally fixes library contents, fit, and controller. The current first-pass coverage target is the eight endpoint bank cells: both models × both suites × nominal 50/500. Anchors from one episode are dependent, and repeated seeds of the same task/init are paired, not new independent initializations.

- For one success probability, the normal-approximation planning rule is `n ≥ 1.96² p(1−p)/h²`: a 95% half-width of 5 pp needs 385 independent episodes at worst-case p=.5, or 139 assuming p=.9; 3 pp needs 1,068 or 385, respectively. Use Wilson/clustered intervals in the actual report. Fifty episodes **per task** do not give precise task-level SR or intervention effects.
- For a paired binary contrast with discordance fraction d and mean contrast near zero, half-width is approximately `1.96 sqrt(d/n)`. At 500 paired episodes and assumed d=.10–.30 it is **2.77–4.80 pp**; at 1,000 it is **1.96–3.39 pp**. At 50 task-level pairs it is **8.77–15.18 pp**. A 500-episode cell can screen substantial effects but cannot generally settle a 1–2 pp quality ranking.
- For a balanced, **unpaired** randomized binary-outcome contrast, the worst-case 95% half-width is about `1.96/sqrt(N)`, requiring approximately **385 / 1,537 / 4,269 independent episode contributions for 10 / 5 / 3 pp**, respectively. Those counts apply to the particular quality stratum being estimated. Repeated anchor outcomes, propensity weighting and rare eligible states can reduce effective precision; 1,537 anchors are not 1,537 independent episode contributions. Log denominators and estimate episode-clustered uncertainty rather than claiming a fixed anchor-count guarantee.
- For continuous residuals, use 30 pilot episodes per bank cell to estimate the SD of an **episode-level** residual summary, then plan `n ≥ (1.96 s_episode/h)²` at the desired half-width h. For conditional estimates, do this within broad predeclared quality strata; start with three strata rather than a task × phase × guard × score cross-product.
- A rough Fisher-transform planning approximation gives about **47 independent library/domain evaluation units** for 80% power to distinguish correlation .4 from zero at a two-sided .05 threshold (30 for .5; 85 for .3). This is not an exact Spearman/clustered power result. More trajectories for the same eight banks reduce SR noise, but do not create independent library-quality examples.

- **What / gap:** For pre-action Q and its components, estimate the difference in later success/short-horizon transition quality caused by choosing the shadow policy chunk instead of the cache chunk. This is **mostly covered by the planned randomization**, unlike the existing broad observational correlations; what must be guaranteed is the propensity of the **actual served treatment**, not just the injection coin. - **Measurement / marginal cost:** Use the existing planned shadow draw for served MISS and store the complete assignment/compliance record. **No extra inference beyond the planned shadow calculation** and small scalar-log overhead. Keep randomization independent of policy sampling and log the future controller policy/version. Sequential randomization identifies an excursion effect under that specified randomized continuation and its visited-state distribution; it does not automatically identify an individual state’s two outcomes or A/B whole-policy SR.
- **Episodes/cells:** Begin with the same **500 episodes in each of the eight endpoint cells** and three broad predeclared quality strata, pooling tasks initially. **Rank 3 — Paired successor and success labels for unserved actions, with validated snapshot restoration.**

- **What / gap:** `next_state(cache)` versus `next_state(policy)` and final success after either choice **from the same anchor**, with an explicitly identical continuation rule afterward. Neither a shadow action nor the factual randomized outcome contains the unchosen successor. Periodic simulator snapshots are **only partly sufficient**: we still need an eligible anchor’s restorable state and later branch executions. A simulator qpos/qvel dump alone is not necessarily a complete experiment state.
- **Granularity / Q1 use:** Per sampled anchor/branch, clustered by its parent episode, with branch-level and final outcome labels. Store simulator/environment state, task progress/termination state, controller/actuator state, random-generator states, pending action/commit buffers, retrieval/guard history, and any policy temporal state required to resume the specified continuation. Include simulator/model/config versions and a replay checksum. This distinguishes density/teacher agreement from physical action competence and turns successor prediction into a matched intervention comparison.
- **Measurement / marginal cost:** During collection, save complete checkpoints at a random or explicitly stratified set of anchors, including high-confidence anchors, with inclusion probabilities and snapshot failures. Periodic-only capture can alias the relevant phase; guard-only capture cannot measure confident failures. Online cost is serialization/I/O and whatever state-copy synchronization restoration requires, not another policy forward pass. A restore-then-replay-the-same-action check must compare control-boundary state and termination with the original; record drift/tolerance rather than declaring feasibility from file existence. A continuation using only A avoids policy calls but estimates a different target from B or pure inference.

The planned shadow at every anchor can advance RNG/policy state, change asynchronous timing, or perturb the rendered/physical trajectory unless isolated. Existing runtime ledgers do not validate this new observer. This is an **instrumentation-validity extension**, not a requested change to A/B.
- **Granularity / Q1 use:** Per decision and per episode, plus a profiling configuration record. Needed before interpreting a new Q–SR relation as library quality rather than observer-induced behavior. Log shadow sampling identity, actual treatment and chunk source, relevant live-state/RNG checks, control deadlines/actual timestamps, stage timings and counts, queue delays, errors, and flags distinguishing served calls, unused shadow calls, extra noise-floor draws and blind-state encodings.
- **Measurement / marginal cost:** Isolate shadow state/RNG; at selected checkpoints compare the same decision with profiling enabled/disabled or replay the baseline trace with shadow side effects suppressed. Log all timing channels without charging unused shadows to A’s *deployment* IR. Randomized serving of an already-computed shadow has zero additional forward cost relative to the profiler, exactly as planned; the physical shadow computation still belongs in the collection-cost ledger. Hash/copy checks and timing instrumentation cost CPU/I/O, and GPU-state synchronization may cost more; measure rather than assign an invented latency.
- **Episodes/cells:** Use **100 matched episode/reset tests per base cell** as a coarse semantic/observer screen, and **300 independent checks** if a zero-detected-failure result is to bound a discrepancy rate below about 1% (not prove equality). Collect timing data from all normal profiler episodes; at least 100 distinct episodes are preferable to thousands of repeated operations on one state. Full matched runs consume episodes; pure offline decision-replay checks may be cheaper but do not establish real-time physical equivalence.

**Rank 12 — The local set of successful actions, not just closeness to one policy action.**

- **What / gap:** Whether several distinct cache/library/policy actions are interchangeable for task success, and the tolerable magnitude/direction of action error around a given state. Cache and policy are only two candidate actions; shadow agreement can be poor while both succeed, or numerically excellent while a small critical error fails. Even the planned randomized experiment does not map that set. This is an **optional branch-study extension** of rank 3.
- **Granularity / Q1 use:** Per sampled anchor/action alternative with matched successors/outcomes, then per task/library. It tests a possible replacement for action-std-normalized RMS: error measured relative to empirically success-preserving action variation. It could explain why a library score ranks within settings but not across tasks or robots.
- **Measurement / marginal cost:** Preserve the candidate chunks and snapshots now. Later branch on cache, saved policy, and a small predeclared set of alternative library chunks or valid perturbations, holding continuation fixed. Respect the robot’s actuator types/constraints; do not interpolate categorical/gripper channels by a universal convention. Each extra alternative costs a branch plus any continuation inference. No new online policy inference is required merely to retain the alternatives; actual validity/success is not an offline distance calculation.
- **Episodes/cells:** Begin with **100 distinct parent episodes per selected cell and three alternatives per anchor** as a mechanism screen, then **200–500 parents** if success differences warrant calibration. Even three alternatives only probe a local part of the action set; they cannot certify a whole tolerance region. Share parents with rank 3 and count uncertainty at the parent-episode level. This is lower priority than obtaining the two fundamental cache/policy outcomes and cannot be promised from one extra logging field.

**Rank 13 — The deployment population for a “global” quality number, if it is not the benchmark’s equal-task average.**

- **What / gap:** Desired task/instruction frequencies, initial-state distribution and any operational success/cost weighting. The library’s episode proportions are acquisition choices, not necessarily deployment frequencies. A balanced simulator collection does not reveal real traffic. This is **unneeded for the report’s explicitly equal-task macro score**, but required to reinterpret it as an operational global prediction.
- **Granularity / Q1 use:** Per deployment population/library with per-episode task/init identities. It sets the averaging distribution for global Q/SR and reveals which task-level uncertainties matter most. It does not change the state-level retrieval score.
- **Measurement / marginal cost:** Declare benchmark weights as configuration, or measure task/init frequencies from representative deployment requests with sampling probabilities. No policy inference is needed just to count requests. Preserve both equal-task and population-weighted summaries; do not retroactively choose weights that improve correlation.
- **Episodes/cells:** **No new episodes** if equal-task weighting is the intended definition. If estimating one task proportion from independent requests, **385 requests** gives a worst-case approximate 5 pp half-width; simultaneous many-task or rare-task estimates need more, and repeated scripted benchmark requests are not an independent operational sample. This requirement is metadata/input to the profiler when the target population is specified externally.

**What not to ask the profiler to collect again.** The all-row LOEO scores, task counts, own-library distance scales, action normalization, candidate diversity, same-task cross-bank searches, fit/bootstrap sensitivity, and fully refitted PCA/metric LOEO are derivable from existing complete keys/actions/episode identities. The last of these was not fully computed in this report, but it is a computation gap, not missing sensor data. Existing success labels, guard outputs, fitted-library manifests and per-episode outcomes should be referenced by stable IDs; the new requirement is completeness/alignment/independence under the new experiment. Additional control policies, learned MISS budgets and triggers are not Q1’s profiler request.
