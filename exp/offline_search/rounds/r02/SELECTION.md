# R2 选题（2026-09-26，协调者；视觉为硬约束）

构思原文见 `NOTES_ideation_A.md`、`NOTES_ideation_B.md`；诊断脚本在 `diag_A/`、`diag_B/`。
四个格子的顺序：π0.5-sp / π0.5-l10 / GR00T-sp / GR00T-l10。err 为执行段误差（越低越好）。
"10×" 指 500 集的库（π0.5 用 bpool_cs，GR00T 用 bpool_all）；"现役规模"指约 50 集的库（current）。

## 两路构思的实测要点

1. **A：按动作相似度白化的联合度量（AWM）**。
   - **做法**：把两路相机的 PCA-64 和 state 拼成 136 维，用一个马氏距离比较。这个距离的几何在库上闭式拟合：对库内每一行，找执行动作最相近、且来自其他集的行，用这些行对的特征差计算协方差 S_w，距离矩阵取 (S_w + λI)⁻¹。然后在全部候选上取 top-16，做核加权均值。
   - **陈旧状态（10×）**：.511 / .437 / .439 / .451。对比 M8 的 .526 / .480 / .453 / .488 和 B0 的 .643–.644，在 40 个"任务 × 格子"上全部胜出。
   - **只用视觉的版本**：.504 / .435 / .445 / .455。白化之后，GR00T 的视觉也追平了 state，R1 中"视觉只帮 π0.5"的现象来自余弦几何本身。
   - **第 0 步**（只用早期步拟合）：.210 / .158 / .255 / .170。
   - **新鲜状态**（加连续性项）：.256 / .275 / .250 / .267，视觉的代价为 0。
   - **现役规模的候选集**（度量在 500 集上拟合）：.562 / .495 / .500 / .493。如果度量在 50 集上拟合，则为 .591 / .512 / .515 / .519。
   - **成本**：每条目 544 B（f16 为 272 B），每套固定开销约 18.5 MB；库总量 27–43 MB，现役为 431–1103 MB；单线程 1.1 ms。
2. **B：可部署的 M8**。
   - **做法**：PCA-32 双相机，按任务去中心化的余弦 z 相加，再加 state 的 z，在全部候选上取核加权 top-8，第 0 步只在同步号的行里选。
   - **陈旧状态**：10× 为 .524 / .454 / .442 / .469，现役规模为 .581 / .511 / .562 / .533。
   - **成本**：288 B/条，库 6–22 MB。
3. **B：陈旧状态的死锁**。
   - 纯缓存失败主要发生在卡住的状态：机器人不动时观测不变，检索每次返回同一行，动作也就不变。
   - 在长时间卡住的片段里，B0 重复选中同一行的比例是 72–83%。
   - 可在线检测的标志：超时、不动（state 加视觉判断）、已走到库轨迹末行、步号滞后。这些标志触发时 err 为 .53–1.11。
   - "恢复"的效果离线测不出来，只能靠闭环验证。
4. **置信度**：陈旧状态下，观测侧信号的 z 和（最近邻距离、分歧度、超时、视觉最大余弦）AURC 为 .319 / .295 / .308 / .333，优于 M8。AWM 自身的置信度更好：.297 / .278 / .299 / .327。
5. **负结果**（以下都实测过）：
   - 夹爪感知的聚类合成、只用成功轨迹建库、第 1 步以后按步对齐、纯轨迹跟踪、CCA、按漂移切换模态、动作聚类分类，都更差。
   - LIBERO 执行时对夹爪取 sign，所以取均值后夹爪上的小数只是离线口径的对冲。报告里同时给出"夹爪 sign 忠实"口径，这个口径下 err 高 +.012 到 +.016。

## 闭环计划（纯缓存，A 池 500 集 × spatial / l10 × π0.5 / GR00T）

- **臂**：
  - CL0：B0 纯缓存，原生路径重跑，作为对照；
  - CL1：V1 AWM 最优配置；
  - CL2：V2 只用视觉；
  - CL3：V1 + V3 保险 + V6 恢复。
- **规模**：4 个臂 × 4 = 16 组 × 500 集；每组约 10–30 分钟，合计约 5–8 小时。
- **先后**：先离线全量，再根据结果定下每个臂的具体配置，最后上闭环。

## owner 裁定（2026-09-26）
- 方法清单照此执行。
- **闭环分两组**：50 集组（现役库）和 500 集组（10× 库），每组 4 个臂。
  - CL0：对照。50 集组用 B0 原生；500 集组用 B0 公式 top-1，候选为大库。
  - CL1：B0 排序 + 前 5 均值，只改合成。
  - CL2：AWM 最优配置。50 集组只用 50 集拟合；500 集组用 500 集拟合。
  - CL3：CL2 + V3 保险 + V6 卡住恢复。
  - 规模：2 组 × 4 臂 × 4 个格子 × 500 集。
- 所有结论按"合成效应 / 方法效应 / 库效应"三层分别报告（§9）。
